# 现有试剂混合筛选：保存状态、明显现象与无明显现象

**调研日期：2026-09-07。用途：从家中旧试剂中选择值得继续开发的实验。**

库存依据：[试剂识别与保存状态评估](试剂识别与保存状态评估.md)，其中最新实物反馈为 2026-07-14。用户本次确认：48 硫酸铜、42 氯化钙、41 氯化钠、4 尿素、34 二氧化硅均未补充，继续按无库存处理。

本次已核对历史清单、保存条件和公开化学资料；**没有检查现在的实物或完成反应预试**。下面的“较高把握”是指名称正确、无污染、按适宜条件配液时，该反应对半年至一年储存造成的常见变化比较耐受，不是实际测得的成功率。旧照片不能证明今天的瓶内状态，也不能把分装瓶等同于供应商的合格原包装。

## 1. 最值得先拿出来核验的组合

**优先找：25 明矾、60 小苏打、49 无水硫酸铜、80 铁钉、84 硫酸铁、24 淀粉、19 碘伏、46 硫代硫酸钠。**

前三项最适合先做小样核验；第四项取决于硫酸铁能否配成可用的澄清液；第五、六项共用旧碘伏，须先验证显色能力。表中的时间只是安排观察窗口的估计，不是旧试剂的实测结果。

| 顺位 | 确切组合与编号 | 能看到什么 | 旧试剂适用性与通过条件 | 动手安排 |
|---|---|---|---|---|
| A1 | **25 明矾溶液＋60 碳酸氢钠溶液** | 两种清液变成白色絮状、胶状沉淀，可能伴随小气泡；通常在数秒至数分钟内可见 | **较高把握。**两种固体都比较耐放，普通结块或结晶水变化通常不妨碍定性反应。分别溶解后应能取得清液；小样须新出现白色絮状物，而非把未溶粉末倒进去 | 核验合格后，可由孩子在监护下滴加预配稀液 |
| A2 | **49 硫酸铜溶液＋60 碳酸氢钠溶液** | 清澈蓝液中出现蓝色至蓝绿色沉淀，可有小气泡；通常较快 | **较高把握。**49 即使已经吸水变蓝，通常仍能提供铜离子；须标签明确、无异常污染，并能配出清澈蓝液。不能改用已耗尽的 48 | 教师配液，控制为滴量；合适浓度及废液收集就绪后可让孩子滴加 |
| A3 | **49 硫酸铜溶液＋80 铁钉** | 铁表面出现红棕色铜层或铜粉，蓝液逐渐变浅；观察约 1–10 分钟 | **较高把握。**铜盐受潮不破坏此用途；铁钉的锈层、镀层或油污会使效果变差。应确认是普通铁钉，清洁局部表面后先试；不保证析出平整、光亮的铜镀层 | 教师配液及处理铁钉尖端；孩子可用工具放入、取出观察 |
| A4 | **84 硫酸铁溶液＋60 碳酸氢钠溶液** | 黄至黄褐色清液形成橙棕／红褐色絮状沉淀，可有气泡 | **中至较高把握。**它本来就是三价铁盐，不存在“二价铁被氧化了就失去这个用途”的问题。但若已经严重水解，无法配出足够清澈的工作液，就不选作现场从清到浑的主实验 | 教师配制并先做滴量示范；是否交给孩子滴加由最终稀液与防护确定 |
| A5 | **24 淀粉＋19 碘伏稀液** | 淀粉出现深蓝、蓝紫至蓝黑色，通常很快 | **条件候选。**干淀粉只要无霉变通常仍可用，旧淀粉液则不沿用；用固体新配。旧碘伏仍呈棕色不能证明足量有效，必须实测与淀粉明显显色，水对照不能出现同样蓝黑色 | 成分、浓度可核对且小样通过后，孩子滴加预配稀液 |
| A6 | **19 碘伏稀液＋46 硫代硫酸钠溶液**；也可先完成 A5，再加入 46 | 棕色褪去；加入已显色的碘—淀粉体系，可见蓝黑色迅速褪去 | **条件候选。**干燥的硫代硫酸钠通常还有此用途，风化影响称量关系多于定性褪色。须新配清液；与等量水对照比较，确认褪色远超单纯稀释。A5 不通过时，不把整条显色—褪色链算可靠 | 核验后可由孩子滴加预配稀液；此组与酸类工作液分开 |

**这些反应分别意味着什么：**

- **A1、A4：生成难溶氢氧化物。**简化净变化分别为 `Al³⁺＋3HCO₃⁻ → Al(OH)₃↓＋3CO₂`、`Fe³⁺＋3HCO₃⁻ → Fe(OH)₃↓＋3CO₂`。A4 的棕色固体用氢氧化铁／水合氧化铁作课堂近似，不写成“碳酸铁”。铝盐、铁盐与碳酸氢钠的反应可见 [Veolia 原技术手册](https://www.watertechnologies.com/handbook/chapter-05-clarification)；将铝离子规律用于钾明矾，是基于其组成的推断。
- **A2：形成含铜碱式碳酸盐沉淀。**实际颜色、含水量和组成随条件变化，不把它一概当作纯 `CuCO₃`。小苏打配铜盐的教学组合见 [John Elfcik 原教学资料，12.1.19](https://johnelfick.github.io/school-science-lessons-web/topics/topicIndexSodium/)；沉淀的组成边界见 [RSC 金属离子与碳酸盐说明](https://edu.rsc.org/download?ac=17360)。后者使用的是碳酸钠，不能拿它的配方直接代替本项小苏打配方。
- **A3：形成新的金属铜。**简化净变化是 `Fe＋Cu²⁺ → Fe²⁺＋Cu`。主要看铁表面，而不是要求短时间内整杯蓝液完全消失。依据：[RSC 金属置换实验](https://edu.rsc.org/experiments/displacement-reactions-between-metals-and-their-salts/720.article)。
- **A5：碘与淀粉形成深色显色体系。A6：硫代硫酸根把碘还原成碘离子。**褪色不代表淀粉消失；显色和褪色是两个过程，三者先后加入不是第三个独立反应。原理依据：[RSC 碘与淀粉、硫代硫酸盐的反应说明](https://edu.rsc.org/experiments/iodine-clock-reaction-demonstration-method/744.article)。该来源的完整碘钟配方不属于本次推荐；这里不加入酸或旧双氧水。

**优先深入的两条观察线：**A1、A2、A4 可以比较“同一种小苏打，遇到不同金属盐，为什么长出不同颜色的固体”；A2、A3 可以比较“同一份蓝色铜盐，遇小苏打形成沉淀，遇铁却析出金属”。若旧碘伏通过，再开发 A5→A6 的显色与消色。这只是筛选方向，不表示这些候选已经实际授课。

## 2. 有意思，但放在第二轮核验

| 组合 | 可能出现的现象 | 为什么没有排在第一轮 |
|---|---|---|
| **14 石蕊＋23 硼砂溶液／21 柠檬酸溶液** | 偏碱时蓝色，偏酸时红色；可比较和改变颜色 | 两种固体通常耐放，瓶中旧石蕊的配方与显色能力需核对。已有紫甘蓝显色授课记录，这属于同类规律的延伸。硼砂原粉由教师处理，不用于徒手玩胶 |
| **16 酚酞＋23 硼砂溶液，之后用21柠檬酸改变酸碱性** | 无色→粉红→无色 | 指示剂溶剂与浓度可能变，须先核对标签并预检。硼砂—酚酞显粉红有 [宾州州立大学的实际演示依据](https://testing.mri.psu.edu/content/antibodies-procedure)；这里只借用化学事实，不采用其免疫学类比 |
| **49 硫酸铜溶液＋7 锌粒** | 红棕色铜析出、蓝色变浅；可能比铁反应快 | 锌表面状态影响启动，反应更可能升温。已有 A3，新增解释价值有限，教师控制的小样备选；不用锌粉替代。依据同上 RSC 置换实验 |
| **50 硫酸镁溶液＋65 新配澄清石灰水** | 白色浑浊／沉淀 | 硫酸镁通常还可用，65 可能已经碳酸化。碱足够时会形成氢氧化镁；视浓度还可能涉及硫酸钙，不能宣称得到纯氢氧化镁。这是基于溶解度与酸碱规律的候选推断，须用实际工作液验证，教师配石灰水 |
| **56 硫酸锌溶液＋60 碳酸氢钠溶液** | 白色含锌碳酸盐／碱式盐沉淀 | 固体通常耐放，但最终显现受浓度等影响，且须收集含锌废液。白色沉淀主题已有 A1，不优先增加金属盐种类；教师微量备选。组合依据同上 John Elfcik 教学资料 |
| **10 活性炭＋少量14石蕊水等已核对成分的稀有色液** | 接触后过滤，滤液颜色可能明显变浅 | 活性炭本体耐放，但吸附能力会受先前吸附、受潮和污染影响。染料太浓或炭粉漏过滤纸会掩盖效果。属于吸附与分离，不是“所有颜色都能被消灭”；不同染料必须分别预试。依据：[RSC 活性炭过滤实验](https://edu.rsc.org/experiments/carbon-filtration-and-activated-charcoal/412.article)；将一般染料吸附用于这瓶石蕊是待验证的推断 |

酚酞的显色区间约为 pH 8.2–10，而常见小苏打水接近这个区间的下缘；**小苏打水没让酚酞明显变红，不能单独证明酚酞坏了。**用标签明确的已知酸、适宜碱液做对照，不能让两瓶状态未知的旧试剂互相“证明合格”。依据：[Oklahoma State University 指示剂表](https://intro.chem.okstate.edu/ChemSource/Acidandbase/acidPage4.html)。

## 3. 效果吸引人，但不计入“旧库存大概率现成可做”

| 组合／想法 | 真实吸引力 | 此次判定 |
|---|---|---|
| **9 硅酸钠＋49 硫酸铜／84 硫酸铁等适当金属盐晶粒** | 形成管状、枝状结构，即化学花园 | **条件不足。**旧水玻璃可能已胶化，浓度和硅碱比未知；粉末铜盐即使仍有效，也不等同于合适晶粒。可能只得到一团沉淀，无法承诺“长花园”。教师掌握溶液状态和晶粒条件后再选，主要生长可跨数小时至隔夜。依据：[RSC 化学花园](https://edu.rsc.org/experiments/making-a-crystal-garden/416.article) |
| **9 硅酸钠溶液＋21 柠檬酸溶液** | 出现乳光、浑浊，适当条件下成凝胶 | **条件不足。**溶胶形成、整杯成胶和凝胶强度不是一回事。旧液已半凝固不能作为漂亮成形的可靠起点，成胶时间强烈依赖配比与 pH。研究确实使用这两种材料，但不能由此承诺几秒成胶：[原始研究](https://journal.ugm.ac.id/ijc/article/view/21834) |
| **35 二氧化锰＋无编号旧双氧水** | 冒泡、氧气产生 | **旧双氧水退出。**35 通常稳定，问题在未知浓度和储存史的双氧水。不要靠催化冒泡测试来确认未知原液的安全浓度；以后若选此题，另用标签完整的新鲜低浓度产品 |
| **44／86 旧“无水”乙酸钠＋水，准备热冰** | 触发后快速结晶并放热 | **不能凭原瓶直接保证。**吸水改变水合状态、溶解关系和配比；物质未必坏了，但不等于已有合格过饱和体系。结晶也是物理变化。依据：[RSC Hot ice](https://edu.rsc.org/exhibition-chemistry/hot-ice/2000049.article) |
| **51 硫酸亚铁或33硫酸亚铁铵＋适宜碱液** | 浅色／绿灰色沉淀随后氧化变棕 | **不作为稳定颜色顺序的主实验。**二价铁比例未知，可能一开始就是棕色混合物；33 还含铵根，不放入自由配对盘 |
| **63 碱式碳酸铜＋21 柠檬酸**；或给 A2 沉淀加柠檬酸 | 有色固体变化、可能溶解并冒泡 | **深化候选。**两种固体本体通常耐放，但柠檬酸络合及可能形成其他含铜固相会影响最终外观，不承诺固定蓝色或完全澄清。与已做过的酸—碳酸盐产气有部分机制重复，只有要研究沉淀去向时再预试 |

现有清单没有可靠确认硫氰酸盐、合适铁氰络合物、银盐等，不能据此补出“血红”“普鲁士蓝”“银镜”等组合。69 号尤其不能靠猜字套入显色实验。也不能把85磷酸二氢钾当成磷酸三钠，把60小苏打当成纯碱。

## 4. 哪些组合基本没有明显新现象

下表以**分别预先溶解、室温、较稀、短时间观察**为前提。每一项都是具体组合，不代表同类所有试剂可以任意互混。溶解本身造成的冷热、加水导致的颜色变浅，也应与混合后是否发生反应分开。

| 具体组合 | 预期观察 | 解释 |
|---|---|---|
| **40 氯化钾＋47／52 硫酸钠** | 保持无色澄清 | 在此条件下通常没有明显净离子反应，可作为溶液混合的对照 |
| **40 氯化钾＋50 硫酸镁** | 保持无色澄清 | 主要是可溶离子共存 |
| **47／52 硫酸钠＋50 硫酸镁** | 通常保持澄清 | 稀溶液下通常没有新沉淀；浓缩结晶另论 |
| **18 蔗糖水＋40 氯化钾水／50 硫酸镁水** | 通常保持无色澄清 | 糖分子与盐的离子混合；不是糖变成了盐 |
| **49 硫酸铜溶液＋47 硫酸钠溶液** | 仍为蓝色，通常因稀释变浅 | 一般不会出现新的明显沉淀；用同体积水对照判断稀释 |
| **81 铜丝＋56 硫酸锌溶液** | 通常不见锌层析出 | 铜不能在普通条件下置换出锌；这条限制比“都是金属所以都会反应”更有价值 |
| **24 淀粉＋18 蔗糖水，冷态** | 可能本来就浑浊，无新的特征显色 | 冷水中的淀粉颗粒不能自动算作反应生成的沉淀 |
| **59 碳酸钙／13 石英砂／92 高岭土＋水或40氯化钾稀液** | 原颗粒分散、悬浮或沉降 | 是已有不溶固体的行为，不是两种清液生成新固体 |

上述无明显净反应判断依据溶解度和金属活动性，是对指定条件的化学推断。不是逐瓶实测报告。

还有一类必须单独区分：**有反应，但肉眼可能看不出来。**例如21柠檬酸与23硼砂，或21柠檬酸与44／86乙酸钠，溶液的酸碱平衡会改变；没有指示剂时仍可能澄清、无色。这些不能教成“完全没有反应”。

同样，**50 硫酸镁＋60 小苏打**不适合作为保证“立刻白浊”或保证“绝无反应”的样品。镁盐的碳酸盐生成受浓度、温度、时间和酸碱状态影响。ACS 常见的快速演示用的是**碳酸钠**与硫酸镁，并非本库存的碳酸氢钠：[ACS Forming a Precipitate](https://www.acs.org/middleschoolchemistry/lessonplans/chapter6/lesson3.html)。

## 5. 半年至一年保存后，各类材料怎样判定

“成分仍在”“还能产生目标现象”“适合孩子操作”是三个判断。受潮、结块、失去结晶水、表面锈蚀，不应一律叫“完全报废”。SDS 的稳定性描述只给出合理预期，不能证明家中分装样品合格。

| 对应编号与材料 | 保存后更可能怎样 | 本次用途判断 |
|---|---|---|
| **18蔗糖、21柠檬酸、25明矾、40氯化钾、47硫酸钠、50硫酸镁、56硫酸锌、60小苏打、83硫酸锰、85磷酸二氢钾** | 常见问题是受潮、结块或水合状态改变；不等于主要成分消失 | 身份和外观正常时，普通溶解、指定定性反应通常值得预试；56、83由教师控制。85的酸式盐性质不能忽略 |
| **49无水硫酸铜、52无水硫酸钠** | 可能已经吸水，原来的“无水”身份不可靠 | 49优先改作铜盐来源；52改作普通硫酸钠。不沿用检水、干燥能力或精确含水量用途 |
| **44无水乙酸钠、86无水醋酸钠** | 两个名称为同一种盐的同义名，可能水合、潮湿 | 不把两个瓶号算作两种独立反应原料；普通溶解可，热冰另配另验 |
| **46硫代硫酸钠** | 固体可能风化；旧溶液的浓度和稳定性另论 | 若为干净固体，可新配并核验碘褪色；不与32亚硫酸钠混淆 |
| **5还原铁粉、7锌粒、80铁钉、81铜丝、93铁屑、95黄铜片** | 表面氧化／锈蚀、油污影响反应速率；主体未必失效 | 适合材料观察。置换优先80，条件适合可备选7；不用粉末来追求更快、更热的反应 |
| **84硫酸铁** | 吸湿、水解，溶液可能预先混浊 | 可配出合适清液才采用A4；严重水解时不靠强酸修复来硬做 |
| **51硫酸亚铁、33硫酸亚铁铵** | 二价铁可能被氧化；33干燥晶体通常比普通亚铁盐更耐保存，但分装史未知 | 不保证二价铁比例及绿→棕序列；33还属于含铵材料 |
| **32无水亚硫酸钠** | 对空气、湿气敏感，氧化会使还原能力下降 | 不把它当可靠还原剂或显色—褪色链首选；不能凭仍是白粉判定有效 |
| **65氢氧化钙、38氧化钙** | 吸收水／二氧化碳，变为其他钙化合物的混合物 | 65须检验新配澄清石灰水是否仍有足够碱性；38退出孩子操作及放热主实验 |
| **9硅酸钠** | 固体或溶液必须先分清；水玻璃可能表面结皮、胶化、浓度改变 | 无法从瓶龄估计“花园”成功率；教师有条件核验后才使用 |
| **14石蕊、16酚酞、19碘伏、6洋红、15品红** | 配方、溶剂、浓度、光照及污染影响使用表现；仅名称不一定能确定完整成分 | 优先核验14、19。16须核对溶剂；6、15不因颜色漂亮就放入孩子自由混合盘，也不假定为安全食用色素 |

| **2木炭、10活性炭、64石墨** | 碳材料本体通常稳定；活性炭吸附性能可能降低 | 材料、吸附、导电观察；不与氧化剂随意配对，不扬尘 |
| **36三氧化二铁、37氧化铜、39氧化铝、68四氧化三铁、35二氧化锰** | 固体通常稳定 | 多数冷态加水无强反应；35缺可靠双氧水，37等不安排混粉加热还原 |

## 6. 明确退出这次自由混合的组合

| 组合／材料 | 退出原因 |
|---|---|
| **32亚硫酸钠＋酸；46硫代硫酸钠＋酸** | 可能释放刺激呼吸道的二氧化硫；46还可生成硫浑浊。看见“白雾／浑浊”不是适合孩子操作的依据 |
| **43氯化铵、62碳酸氢铵、33硫酸亚铁铵＋碱性材料** | 可能释放氨；不以闻味为观察目标，也不加入含碱的混合废液 |

## 7. 怎样把筛选落实成“上课大概率有效”

1. **先核对身份与包装。**记录实际标签、固体／溶液、瓶盖、霉变、明显污染和异常结皮。不尝、不闻瓶口；漏液、鼓胀、结晶堵盖的未知样品不由孩子开启。
2. **只为选中的组合准备工作液。**从合格固体新配少量稀液，使用新鲜、来源清楚的实验用水。仅为颗粒过滤或“看起来清澈”不能洗白身份不明／疑似污染的旧样品。
3. **每种做水对照，再做目标配对。**用预配的适宜稀液进行滴量至约1 mL的小样；这不是拿任意浓度原液按统一体积混合。沉淀组确认两种原液本身清澈；褪色组确认变化超过等量加水。
4. **用课堂同一批液、同一顺序连续复现两次。**记录是否通过、等待时间和最终外观。只有实测通过的组合进入孩子的配对表；没有变化就保留观察结果，不靠不断加料、加热或加入第三种未知材料挽救。
5. **孩子只操作当次列明的配对。**佩戴合身护目镜，在托盘里操作，每瓶专用滴管。原粉、高风险配液与表面处理由教师完成；留给孩子预测、滴加、比较和记录。
6. **每个反应单独收尾。**含铜、含锌残液和沉淀收集为有标签的实验废物，按当地合适渠道处置，不倒入水槽；其他实验余液也不跨组汇总后随意“中和”。

最适合保留孩子“想逐个混起来看看”的方式，是让他面对一张**已筛选的具体配对表**，观察哪些生沉淀、哪些显色／褪色、哪些与水对照近似。现阶段先从A1、A2、A3核验，A4合格后加入；A5与A6在旧碘伏实际显色通过后加入。
