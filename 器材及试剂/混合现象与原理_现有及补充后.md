# 混合现象与原理：现有试剂与补充后可做的实验

## 一、现有试剂：预检通过后可做

| 组合 | 可能看到的现象 | 备注 | 原理／化学方程式（教师参考） |
|---|---|---|---|
| **A1 明矾＋小苏打**<br>25＋60 | 两种清液混合后出现白色、蓬松的絮状沉淀，可能伴有小气泡。 | **优先。**两种固体通常耐放；先分别溶解，避免把未溶粉末当沉淀。[依据](https://www.watertechnologies.com/handbook/chapter-05-clarification) | 形成氢氧化铝。<br>Al³⁺ + 3HCO₃⁻ → Al(OH)₃↓ + 3CO₂↑ |
| **A2 硫酸铜＋小苏打**<br>49＋60 | 清澈蓝液出现蓝色至蓝绿色絮状沉淀，可能有气泡。 | **优先。**49吸水变蓝后通常仍可用；48已耗尽。式中产物为代表性组成，实际可能含不同水合／碱式盐。[依据](https://edu.rsc.org/download?ac=17360) | 形成含铜碱式碳酸盐；代表性简化式：<br>2Cu²⁺ + 4HCO₃⁻ → Cu₂(OH)₂CO₃↓ + 3CO₂↑ + H₂O |
| **A3 硫酸铜＋铁钉／锌粒**<br>49＋80／7 | 金属表面出现红棕色铜层或铜粉，蓝液逐渐变浅；铜层不一定平整光亮。 | **优先铁钉。**先检查锈层、镀层和油污；锌粒反应可能较快并升温，由教师控制。[依据](https://edu.rsc.org/experiments/displacement-reactions-between-metals-and-their-salts/720.article) | 铁／锌置换出铜。<br>Fe + Cu²⁺ → Fe²⁺ + Cu↓<br>Zn + Cu²⁺ → Zn²⁺ + Cu↓ |
| **A4 硫酸铁＋小苏打**<br>84＋60 | 黄褐色清液中出现橙棕／红褐色絮状沉淀，可能伴有气泡。 | 84须能配出合适清液；若已严重水解，补新硫酸铁。Fe(OH)₃是水合铁氧化物的常用近似。[依据](https://www.watertechnologies.com/handbook/chapter-05-clarification) | Fe³⁺ + 3HCO₃⁻ → Fe(OH)₃↓ + 3CO₂↑ |
| **A5 淀粉＋碘伏**<br>24＋19 | 很快出现深蓝、蓝紫至蓝黑色；可与水、糖水比较。 | 干淀粉无霉变才新配。旧碘伏必须实际显色，仍呈棕色不算合格；失败就补新适用含碘材料。[依据](https://edu.rsc.org/experiments/iodine-clock-reaction-demonstration-method/744.article) | 碘／多碘离子与淀粉形成深色显色体系；不写单一方程式。 |
| **A6 碘伏＋硫代硫酸钠**<br>19＋46；也可接在A5之后 | 棕色碘液褪色；若先加入淀粉显色，再加46，可看到蓝黑色消失。 | 46干净固体可新配预检。与等体积加水对照，确认不是单纯稀释；**不另加酸**。[依据](https://edu.rsc.org/experiments/iodine-clock-reaction-demonstration-method/744.article) | 碘被还原为碘离子，淀粉没有因此消失。<br>I₂ + 2S₂O₃²⁻ → 2I⁻ + S₄O₆²⁻ |
| **A7 指示剂＋硼砂／柠檬酸**<br>14石蕊或16酚酞＋23／21 | 石蕊：酸性红、碱性蓝。酚酞：适宜碱性时粉红，加酸后无色。 | 先核对指示剂配方并预检，失败补新；小苏打水显红不明显不能单独证明酚酞失效。与已做紫甘蓝显色同类。[依据](https://testing.mri.psu.edu/content/antibodies-procedure) | 指示剂在不同酸碱形式下颜色不同；不以通用模型代替具体分子方程式。 |
| **A8 硫酸锌＋小苏打**<br>56＋60 | 在合适浓度下形成白色沉淀，可能有气泡。 | 教师微量备选。实际沉淀可能含碱式盐，式中ZnCO₃为简化表示。[依据](https://johnelfick.github.io/school-science-lessons-web/topics/topicIndexSodium/) | Zn²⁺ + 2HCO₃⁻ → ZnCO₃↓ + CO₂↑ + H₂O |
| **A9 活性炭＋稀有色液**<br>10＋已核对的14石蕊水等 | 接触、过滤后，滤液颜色可能明显变浅。 | 每种染料分别预试；炭粉漏过滤材会掩盖效果。6洋红、15品红不当作食用色素。[依据](https://edu.rsc.org/experiments/carbon-filtration-and-activated-charcoal/412.article) | 有色组分被吸附到炭表面，属于吸附与分离，无通用方程式。 |
| **A10 琼脂＋水**<br>87；加热后冷却 | 热时可流动，冷却后成凝胶；再充分加热可重新流动。 | 干琼脂无霉变才用；教师加热，不是两种清液接触即成胶。[依据](https://arxiv.org/abs/1603.00778) | 多糖冷却后形成物理网络，将水固定其中；无普通化学方程式。 |
| **无明显现象的对照**<br>40氯化钾＋47／52硫酸钠；40＋50硫酸镁；18蔗糖水＋40 | 通常保持无色澄清；49硫酸铜液＋47硫酸钠液通常仍蓝，只因稀释变浅。 | 指室温、较稀、先分别溶解的条件。柠檬酸＋硼砂即使无色澄清，仍有酸碱平衡变化。 | 前几组主要为溶质混合，通常无明显净离子反应；“看不见变化”不等于“没有反应”。 |
| **通用备注** | “现有”指库存记录中有，**尚未实测合格**；新旧工作液均先做小样。 | 教师配液、处理原粉与加热；孩子戴护目镜、用专用滴管操作指定配对。含铜、含锌废物收集，不混合各组剩液。 | 方程式供教师参考；↓沉淀，↑气体。保存详情见[库存评估](试剂识别与保存状态评估.md)及[调研依据](现有试剂混合筛选_2026-09-07.md)。 |

## 二、补充试剂后：可增加或恢复的现象

| 实验／组合 | 需要补充什么 | 可能看到的现象 | 备注 | 原理／化学方程式（教师参考） |
|---|---|---|---|---|
| **B1 化学花园**<br>水玻璃＋硫酸铜晶粒 | 新鲜、规格明确的9硅酸钠水玻璃；补48五水硫酸铜晶粒 | 晶粒外先出现沉淀壳，再逐渐长出蓝绿色细管、枝条或“小烟囱”；可连续观察至数小时或隔夜。 | **优先候选。**晶粒、浓度和硅碱比影响形态，先预试；水玻璃较强碱性，教师操作。实际管壁为复杂含铜、含硅固体。[依据](https://pubs.acs.org/doi/10.1021/acsomega.7b00930) | 沉淀成膜＋渗透进水＋破膜流出，推动管壁生长。局部反应如：<br>Cu²⁺ + 2OH⁻ → Cu(OH)₂↓<br>不能用这一条式子概括整个花园。 |
| **B2 水玻璃＋柠檬酸**<br>利用现有21 | 新鲜、规格明确的水玻璃 | 出现乳光、浑浊；配比合适时逐渐成胶、失去流动性。 | 教师配制；成胶时间取决于浓度、pH和温度，不保证几秒完成。[依据](https://journal.ugm.ac.id/ijc/article/view/21834) | 硅醇缩合形成网络，代表性步骤：<br>≡Si–OH + HO–Si≡ → ≡Si–O–Si≡ + H₂O<br>≡表示其余网络连接，不是三键。 |
| **B3 双氧水产氧／泡沫**<br>可利用现有35二氧化锰 | 新鲜**3%双氧水**；泡沫版另备**酵母、普通洗洁精** | 冒出氧气气泡并升温；洗洁精留住气体，形成低浓度“大象牙膏”泡沫。 | **优先候选。**二氧化锰版由教师控制；酵母版适合孩子参与。容器敞口，不摸泡沫、不点燃气体；3%不承诺剧烈喷涌。[依据](https://aglab.ars.usda.gov/let-s-get-to-work/elephant-toothpaste) | MnO₂或酵母中的酶加快分解；洗洁精不参与净反应。<br>2H₂O₂ → 2H₂O + O₂↑ |
| **B4 热冰**<br>三水合乙酸钠＋晶种 | 水合状态明确的**三水合乙酸钠**，替代旧44／86 | 提前制好的过饱和体系遇晶种后快速结晶，形成白色晶体团或小塔，并放热。 | **优先候选。**教师提前加热、充分冷却，孩子可触发晶种；避免残留晶粒导致提前结晶。[依据](https://edu.rsc.org/exhibition-chemistry/hot-ice/2000049.article) | 结晶放热；理想化表达：<br>Na⁺(aq) + CH₃COO⁻(aq) + 3H₂O(l) → CH₃COONa·3H₂O(s) |
| **B5 氯化钙＋小苏打**<br>利用现有60 | 补42氯化钙，成分与水合状态明确 | 两种清液混合后白浊，生成白色碳酸钙沉淀，并可见小气泡。 | 先分别配液；与已做钙盐—小苏打沉淀机制重复，作为可恢复组合保留。[依据](https://www.acs.org/middleschoolchemistry/lessonplans/chapter6/lesson3.html) | Ca²⁺ + 2HCO₃⁻ → CaCO₃↓ + CO₂↑ + H₂O |
| **B6 凝胶小球／细条**<br>氯化钙＋海藻酸钠 | 补42氯化钙；**新增海藻酸钠**，着色时另备食用色素 | 液滴接触钙液，从外层开始成胶；滴入形成小球，连续挤入形成细条。 | **优先候选。**教师提前充分分散海藻酸钠并配稀钙液，孩子控制滴加与形状；制品不入口。[依据](https://edu.rsc.org/experiments/cross-linking-polymers-alginate-worms/691.article) | 钙离子交联多糖链。基团示意：<br>2R–COO⁻ + Ca²⁺ ⇌ (R–COO)₂Ca<br>R为聚合物链段。 |
| **B7a 硫酸镁＋石灰水**<br>利用现有50 | 新鲜65氢氧化钙，现配澄清石灰水；或标签完整的有效石灰水 | 出现白色沉淀。 | 石灰水碱量须预试；可能混有硫酸钙，不能当作纯氢氧化镁。教师配液。 | Mg²⁺ + 2OH⁻ → Mg(OH)₂↓ |
| **B7b 硫酸铜＋石灰水**<br>利用现有49 | 同B7a | 出现蓝色沉淀。 | 可能混有硫酸钙；含铜废物收集。 | Cu²⁺ + 2OH⁻ → Cu(OH)₂↓ |
| **B7c 硫酸亚铁＋石灰水** | 同B7a，另补新鲜51硫酸亚铁，临用配液 | 浅绿／绿灰色沉淀接触空气后逐渐变棕。 | 教师控制；不用含铵的33替代51。以石灰水提供OH⁻是待预试应用，参考方法用NaOH；实际产物可更复杂。[依据](https://edu.rsc.org/experiments/oxidation-states-of-iron/517.article) | Fe²⁺ + 2OH⁻ → Fe(OH)₂↓<br>4Fe(OH)₂ + O₂ + 2H₂O → 4Fe(OH)₃↓ |
| **B8 无水硫酸铜＋水** | 若49已吸水，另补少量真正无水硫酸铜 | 近白色粉末接触少量水后变蓝，可伴随放热。 | 教师微量演示；仅为白→蓝另购。A2、A3不要求无水型；水过量会溶解。[依据](https://edu.rsc.org/download?ac=12432) | 水合固体形成的简化式：<br>CuSO₄ + 5H₂O → CuSO₄·5H₂O |
| **B9 维生素C碘钟**<br>利用现有24淀粉 | 新鲜适用含碘材料、3%双氧水；**新增维生素C**及选定配方所需酸性条件 | 先无明显深色，等待后突然呈深蓝至蓝黑色；只用维生素C与碘则表现为褪色。 | **优先候选。**教师按同一验证配方预配，孩子混合、计时。碘伏不与碘酊按同体积互换；21柠檬酸仅在配方允许时使用。[依据](https://pubs.acs.org/doi/10.1021/ed079p41) | 双氧水生成碘，维生素C消耗碘；维生素C耗尽后淀粉显色。<br>H₂O₂ + 2I⁻ + 2H⁺ → I₂ + 2H₂O<br>C₆H₈O₆ + I₂ → C₆H₆O₆ + 2I⁻ + 2H⁺ |
| **恢复已有显色／褪色** | 若旧19碘伏、14石蕊、16酚酞预检失败，补对应标签完整的工作液 | 恢复A5、A6、A7的现象。 | 补新提高可靠性，不算新增反应；46硫代硫酸钠失败时也更换。 | 见A5—A7。 |
| **恢复已做的溶解冷热与对照** | 补4尿素、42干燥且水合状态明确的氯化钙、41氯化钠 | 尿素溶解降温；无水氯化钙溶解升温；氯化钠溶解温变较小。 | 已做过，不优先重复。34二氧化硅不必为新现象补货，颗粒观察仍有13石英砂等。 | 溶解表达式：<br>CO(NH₂)₂(s) → CO(NH₂)₂(aq)<br>CaCl₂(s) → Ca²⁺(aq) + 2Cl⁻(aq)<br>NaCl(s) → Na⁺(aq) + Cl⁻(aq) |
