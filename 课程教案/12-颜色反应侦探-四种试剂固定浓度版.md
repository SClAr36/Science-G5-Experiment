# 第 12 节：颜色反应侦探（四种试剂固定浓度版）

**实验试剂**

| 试剂 | 本课使用规格 | 备量 |
|---|---|---:|
| **碘液（iodine solution）** | 新的 **2% 碘酊**，标签注明含碘化物；一次配成 **0.5% 碘液**，全程使用 | 0.5% 碘液 20 mL |
| **淀粉（starch）** | 一次配成 **1% 淀粉液**，全程使用 | 1% 淀粉液 50 mL |
| **维生素 C（ascorbic acid）** | 纯抗坏血酸粉末，一次配成 **1% 溶液**，全程使用 | 1% 维生素 C 液 20 mL |
| **双氧水（hydrogen peroxide）** | 新的、标签明确的 **3% 过氧化氢溶液** | 50 mL |

1. **淀粉液＋碘液 → 蓝黑色（blue-black），用来检测淀粉。**<br>
   <span style="color: #234E78;">淀粉中的<strong>直链淀粉（amylose）</strong>像卷起来的小弹簧；碘与它结合，就会显出蓝黑色。</span>

2. **蓝黑色液＋维生素 C → 褪色（fading）；再补碘 → 蓝黑色恢复。**<br>
   <span style="color: #234E78;">维生素 C 先和碘反应，颜色褪去；淀粉仍在，补足碘就能再次显色。</span>

3. **碘液＋维生素 C＋淀粉液，再加双氧水 → 先近无色，后突然变蓝黑。**<br>
   <span style="color: #234E78;">维生素 C 先把新出现的碘用掉；等维生素 C 用完，碘才留得下来，让淀粉变蓝黑。</span>

4. **备选：用碘液和蓝黑色液，辨认水、淀粉液、维生素 C 液。**<br>
   <span style="color: #234E78;">淀粉遇碘会显色，维生素 C 能使蓝黑色液褪色；把两次结果放在一起，判断每杯是什么。</span>

### 0–4 分钟

1. 戴好护目镜和手套，把杯子放进托盘。
2. 按标签摆好溶液，各液使用对应滴管。
3. 核对试剂标签，准备称量、量取和配液。

### 4–25 分钟：一起配液

按文末“课堂配液方法”配好四种固定浓度试剂。教师加热淀粉时，孩子量取、配制碘液和维生素 C 液；淀粉冷却后共同补水、混匀、贴标签。将各液放至室温再做实验。

### 25–33 分钟：淀粉液＋碘液

**预期现象**：滴入后，淀粉杯很快变成深蓝至蓝黑色；水杯和糖水杯保持碘液的黄棕色，不变蓝黑。

<p style="color: #234E78;"><strong>原理：</strong>淀粉里的直链淀粉是一种长长的分子（molecule），能卷成小弹簧一样的形状。碘进入里面，与它结合，就会显出蓝黑色。</p>

先看水、糖水和淀粉液，预测哪一杯加碘后会变深。

1. 三杯分别加入 **5 mL 水、5 mL 糖水、5 mL 1% 淀粉液**。
2. 每杯加 **2 滴 0.5% 碘液**，轻晃混匀。
3. 并排观察，记下三杯颜色。

#### 记录与板书

| 样品（sample） | 加碘后的颜色 |
|---|---|
| 水 | __________ |
| 糖水 | __________ |
| 淀粉液 | __________ |

<p style="color: #234E78;">淀粉＋碘 → 蓝黑色。</p>

### 33–43 分钟：蓝黑色液＋维生素 C

**预期现象**：加维生素 C 后，蓝黑色逐渐褪去；加同量水的杯子仍显深色。向褪色杯继续补碘，蓝黑色重新出现。

<p style="color: #234E78;"><strong>原理：</strong>维生素 C 和碘反应，把它变成另一种形态，叫碘离子（iodide）。碘离子不能让淀粉变蓝，所以颜色褪去，淀粉还在。继续补碘，等剩余的维生素 C 用完，颜色就会回来。</p>

1. 将 **30 mL 1% 淀粉液＋1 mL 0.5% 碘液**混匀，得到蓝黑色液。
2. 分入两杯，各 **10 mL**；剩余约 11 mL 留给最后的备选识别任务。
3. 第一杯逐滴加入 **1% 维生素 C 液**，每滴后轻晃，直到褪色，记下滴数。
4. 第二杯作为**对照（control）**，加入**相同滴数的水**，比较两杯。
5. 向褪色杯逐滴补加 **0.5% 碘液**，每滴后轻晃，直到蓝黑色保持 10 秒。

#### 记录与板书

| 加入什么 | 滴数（drops） | 颜色 |
|---|---|---|
| 维生素 C | ______ | __________ |
| 等滴数的水 | ______ | __________ |
| 向褪色杯补碘 | ______ | __________ |

<p style="color: #234E78;">颜色褪去，淀粉还在；补足碘，颜色回来。</p>

### 43–55 分钟：再加双氧水，做碘钟（iodine clock）

**预期现象**：加入双氧水后，溶液先保持近无色，过一会儿迅速变成蓝黑色。第二杯维生素 C 较多，通常等待更久。

<p style="color: #234E78;"><strong>原理：</strong>双氧水把碘离子变回碘。维生素 C 又马上把碘变回碘离子，所以蓝黑色暂时出不来。等维生素 C 用完，碘能留下来，遇到淀粉就变蓝黑。</p>

用两个干净杯重新量取试剂；表中每一列是一杯的完整配方，先做第一杯，再做第二杯。先预测（prediction）：多加一点维生素 C，等待时间会怎样变化？

| 加入的溶液 | 第一杯 | 第二杯 |
|---|---:|---:|
| **1% 维生素 C 液** | **2.5 mL** | **3.0 mL** |
| 0.5% 碘液 | 6 mL | 6 mL |
| 1% 淀粉液 | 3 mL | 3 mL |
| 水 | 10.5 mL | 10.0 mL |
| **最后加入：3% 双氧水** | **8 mL** | **8 mL** |
| 总体积 | 30 mL | 30 mL |

1. 加入维生素 C 液和碘液，轻晃至碘的颜色褪去。
2. 加入淀粉液和水，混匀。
3. 将量好的双氧水一次倒入，**接触时开始计时**，持续轻轻搅匀。
4. 出现蓝色并持续 **3 秒**时停止计时，记录用时。
5. 换干净杯，按第二杯用量再做一次。保持室温、混合方式和停止计时的标准相同。

|---|---|
| 第一杯：2.5 mL 维生素 C 液 | __________ |
| 第二杯：3.0 mL 维生素 C 液 | __________ |

本次等待更久的是第____杯。

<p style="color: #234E78;">维生素 C 先用完，蓝黑色才出现。</p>

### 备选：辨认 A、B、C（另需约 8–10 分钟）

前三项实验提前完成，且除收拾外仍有 8–10 分钟时再做；否则跳过。使用第二个实验预留的蓝黑色余液。

**预期现象**：淀粉样品加碘液变蓝黑；维生素 C 样品能使蓝黑色液褪色；水在两次测试中分别保留碘液的黄棕色和蓝黑色液的深色。

<p style="color: #234E78;"><strong>原理：</strong>有淀粉，加碘会变蓝黑；有维生素 C，蓝黑色液会褪色。清水只是让颜色淡一些。把两次结果放在一起，就能找到这三份样品。</p>

三份样品分别是水、淀粉液、维生素 C 液，各取 5 mL，随机贴上 A、B、C，记下答案。先选一种测试，再用另一种补齐判断。

1. 从各样品取 **2 mL** 到新杯，各加 **2 滴 0.5% 碘液**。
2. 再从 A、B、C 各取 **2 mL 未测试过的样品**，各加 **1 mL 第二个实验预留的蓝黑色液**，轻晃。
3. 按下面的颜色规律写出判断，再揭开编码答案。

| 样品 | 加碘液 | 加蓝黑色液 |
|---|---|---|
| 淀粉液 | 变蓝黑 | 保持深色 |
| 维生素 C 液 | 保持浅色 | 褪色 |
| 水 | 保持黄棕色 | 保持深色 |

### 课堂配液方法（对应 4–25 分钟）

用纯净水，与孩子一起完成称量、量取、补水和贴标签；教师负责淀粉加热及碘酊原液处理。配液计入课堂时间，淀粉加热和冷却期间交叉完成另外两种溶液的配制。课堂只摆放 **1% 淀粉液、0.5% 碘液、1% 维生素 C 液、3% 双氧水**四种固定浓度试剂；课堂使用室温溶液。

- **0.5% 碘液 20 mL**：量取 **5 mL 新的 2% 碘酊**，加纯净水补至 **20 mL**（约加 15 mL 水），混匀，贴“碘液 0.5%”。浓度换算：2% × 5 ÷ 20＝0.5%；全课只配这一瓶 20 mL 碘液。
- **1% 淀粉液 50 mL**：称取 0.5 g 淀粉，加少量冷水调匀，加入约 20 mL 热水并搅拌，加热至糊化；冷却后转入量具，用水补至 50 mL，混匀，贴“淀粉液 1%”。
- **1% 维生素 C 液 20 mL**：称取 0.5 g 抗坏血酸，用少量水溶解后补至 20 mL，得到配制过程中的 2.5% 液；混匀后取 8 mL，用水补至 20 mL，混匀，贴“维生素 C 1%”。剩余 2.5% 液移出实验用液区；后续实验只取这瓶 1% 液，当天配制。
- **3% 双氧水 50 mL**：直接使用标签明确的新成品，不再稀释。
- **对照糖水**：1 g 蔗糖溶解后补水至 20 mL。A、B、C 样品只在决定做备选实验时再分装。

**课前核对**：按课堂用量预试显色、褪色及两杯碘钟。上表为课堂备量，预试用液另按同法备取。记下碘钟用时；碘钟的 12 分钟按两杯均在 **2 分钟内显色**估算；配液与两杯操作时间需一并核实。此版已核对配比，尚无实物预试记录。

淀粉和蔗糖可从库存 24、18 号取用，先核对标签与保存状态；碘酊、维生素 C 和 3% 双氧水按上表补齐。

**另备**：透明小杯 15 个（其中 2 个容量至少 60 mL）、带刻度滴管及量筒、电子天平、耐热配液杯及加热和冷却用具、各液分装瓶、白底托盘、计时器、标签、护目镜、手套和擦拭纸。家长准备小杯、纯净水约 500 mL、标签和擦拭纸；教师带试剂、量取工具和防护用品。

**教师参考**：显色涉及直链淀粉中的碘／多碘链复合物；“小弹簧”比喻直链淀粉的螺旋结构。维生素 C 将碘还原为碘离子，自身被氧化；双氧水再将碘离子氧化为碘。碘钟的酸性条件由抗坏血酸及前段反应提供；碘酊中的碘化物参与碘的再生成。第一杯的 6 mL 0.5% 碘液＋10.5 mL 水，等同于来源中的 1.5 mL 2% 碘酊＋15 mL 水；第二杯增加 0.5 mL 维生素 C 液、等量减水。淀粉液采用 [AACT 的 1% 配法](https://teachchemistry.org/classroom-resources/vitamin-c-quality-control)。等待时间由维生素 C 的剩余量与碘的生成速率共同决定。本稿为教学改编，实物用时在课前填写。
