## 下一阶段设计约束

- 每次课程共 **45–60 分钟**（2026-09-06 更新）。
- 学校内容按当周需要简短复习，计入总课时，不再固定预留 15–30 分钟。
- 每课提供 45 分钟可完整收束的基础版本，最多扩展至 60 分钟；包含孩子实际搭建、操作、解释、记录与收拾的时间。
- 先确定总问题、核心模型和逐课概念依赖，再选择有趣且能提供证据的实验；每课说明对前后课的作用。
- 连续系列通常用 4–5 节围绕一个总问题深入；每课写清核心问题、实验、孩子要发现的规律和原理关联。
- 当前化学、物理与工程系列及强视觉化学专题统一见 [系列课程方案总目录](../系列课程方案/60分钟课程重整/README.md) / [HTML 阅读版](../系列课程方案/60分钟课程重整/README.html)。实际授课状态不变。
- 当前整合稿与[原版系列](../系列课程方案/原版本/README.md)分别维护；模块编号与课数以各自目录为准。
- 不再安排酸与小苏打的重复产气或测温实验。
- 原稿、逐课实验与反应说明及修改记录见 [课程方案对照](../arxiv/%E8%AF%BE%E7%A8%8B%E8%A7%84%E5%88%92%E9%98%B6%E6%AE%B5/03-%E5%8E%9F%E7%A8%BF%E4%B8%8E%E4%BF%AE%E8%AE%A2%E5%AF%B9%E7%85%A7/README.md)。
- DK 检索背景与额外食品化学素材见 [混合专题原合辑](../arxiv/%E8%AF%BE%E7%A8%8B%E8%A7%84%E5%88%92%E9%98%B6%E6%AE%B5/05-%E5%85%AD%E7%B3%BB%E5%88%97%E5%8E%9F%E5%90%88%E8%BE%91/%E5%8C%96%E5%AD%A6%E6%B7%B7%E5%90%88%E4%B8%93%E9%A2%98_DK%E4%B8%8E%E5%85%AC%E5%BC%80%E6%95%99%E6%A1%88%E6%A3%80%E7%B4%A2.md)；日常选课与修改以总目录中的独立系列为准。

## 统一备课原则

- 每节课围绕一个可以检验的核心问题展开。
- 先让学生作出有理由的猜想，再讨论怎样测量。
- 不把实验变成只需照步骤操作的演示。
- 明确自变量、因变量和需要控制的条件。
- 尽量进行重复测量，保留真实的数据波动和异常现象。
- 结论必须说明依据了哪些实验结果。
- 猜想与结果不一致时，修改猜想或解释，不修改实验记录。
- 公式和术语用于概括已经发现的规律，不作为课堂起点。
- 重要科学概念在首次出现时同时标注准确的英文术语，便于国际学校课堂中进行中英文对应。

## 新教案的写法

先列关键实验试剂，再用几句话说明“什么＋什么”。每个实验先写预期现象和孩子能理解的原理，关键词后括号标注英文，再写简短操作；实验后保留可折叠的记录与板书。只有原理和原理性结论标深蓝，其余采用黑白版式。具体规则见 [项目规则](../AGENTS.md)。
