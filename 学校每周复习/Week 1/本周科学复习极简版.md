# Week 1 Science — Quick Review

## English

- **Scientific method:** Observation / Question → Research → Hypothesis → Experiment → Analyze Data → Conclusion
- **Observation:** information gathered with the senses
- **Inference:** a logical assumption based on observation and prior experience
- **Data:** qualitative = descriptions; quantitative = numbers / measurements
- **Tools:** graduated cylinder, ruler, balance, beaker
- **SI / metric system (vs. customary units):** <small>SI = International System of Units.</small> Standard units help scientists compare, communicate, repeat, and check results
- **Units:** length—meter; mass—gram; volume—liter; temperature—kelvin
- **Metric ruler:** centimeter (cm) / millimeter (mm)
- **Metric ladder:** kilo → hecto → deka → unit → deci → centi → milli
- **Conversion:** smaller unit → decimal right; larger unit → decimal left; `4 km = 4000 m`

## 中文版

- **科学方法：**观察 / 问题 → 研究 → 假设 → 实验 → 分析数据 → 结论
- **观察：**用感官收集的信息
- **推断：**根据观察和已有经验作出的合理假定
- **数据：**定性 = 描述；定量 = 数字 / 测量
- **工具：**量筒、尺、天平、烧杯
- **SI / 公制（对应 customary units / 习惯单位制）：**<small>SI = International System of Units（国际单位制）。</small> 统一单位便于科学家比较、交流、重复和检查结果
- **单位：**长度—米；质量—克；体积—升；温度—开尔文
- **公制尺：**厘米（cm）/ 毫米（mm）
- **公制阶梯：**kilo → hecto → deka → 基本单位 → deci → centi → milli
- **换算：**换成小单位 → 小数点右移；换成大单位 → 小数点左移；`4 km = 4000 m`
