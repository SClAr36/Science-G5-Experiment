## 编辑规则

- 共同修改仍以 Markdown 为准，只处理文字、标题、列表和表格；每轮不自动生成 HTML、Word、PDF。用户确认后，可按指定课次回填现有 Word。
- 修改前读取 Markdown 的最新保存内容；不要从旧 Word 重新生成并覆盖它。Word/PDF 上的旧稿不再作为当前文字依据。

- 只在当前文件上继续改，不新增“新版”“家长版”等同内容文件。临时检查文件放在临时目录。
- 每次先读取最新保存内容。同一份本地 Word 交替编辑、交替保存；文件被占用时等用户保存关闭后再核对、写入。
- 元宝个人反馈用灰紫色 `#80627D`。用户提到“课上出现的情况”时，最终 Word 使用与酒精灯情况相同的说明块：沿用蓝色说明块的段落样式、缩进和留白，使用浅暖灰底色 `#F8F4EC` 与细侧线 `#C2AD88`；直接写内容，不加“临时替换”“未做”“新增”“后续记录”等分类标题。Markdown 中在对应段落前保留不可见的 Word 样式备注。
- 学校对应总表按 Unit 1→2→3→4，再按 Notes 编号排列；Homework 放在所属 Unit 的 Notes 后。同一学校材料合并为一行，对应课次放在后面，仅 Unit 名称栏着色，右侧内容保持白底：Unit 1 淡蓝 `#EEF4FA`、Unit 2 米色 `#F6F2E8`、Unit 3 浅绿 `#EEF5F0`、Unit 4 浅紫 `#F3EFF6`。
- 三态图使用 Word 原生小方框、箭头与文字，字号接近正文；不再使用大幅图片。

- 参考用户已改好的第1–4课：研究问题简短，实验写清做什么、发生什么、说明什么；用孩子和家长能理解的科学语言，按内容安排分点和知识小结，不套固定格式。英文关键词就地标注，按用户指定课次逐节修改。
- 每次修改反馈 Markdown 后，在右侧重新打开文件并尽量定位到修改处，同时在回复中提供文件入口。

- 开头使用“Learning Update”；页脚仅保留页码，不写“家长版”。不加“九次课做了哪些实验”一类大标题，概述后直接列各课。

- 改写前逐项核对正式教案的实验清单、分项操作和已确认的课堂记录。突出知识主线不能省略实验或擅自改编号；导入、回顾与新实验分清，教案预期不冒充实际测量结果。
