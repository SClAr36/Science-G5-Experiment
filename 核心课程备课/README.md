## 统一备课原则

- 每节课围绕一个可以检验的核心问题展开。
- 先让学生作出有理由的猜想，再讨论怎样测量。
- 不把实验变成只需照步骤操作的演示。
- 明确自变量、因变量和需要控制的条件。
- 尽量进行重复测量，保留真实的数据波动和异常现象。
- 结论必须说明依据了哪些实验结果。
- 猜想与结果不一致时，修改猜想或解释，不修改实验记录。
- 公式和术语用于概括已经发现的规律，不作为课堂起点。
- 重要科学概念在首次出现时同时标注准确的英文术语，便于国际学校课堂中进行中英文对应。

## 每份备课稿的结构

1. 课程定位与核心问题
2. 学习目标和概念边界
3. 材料与教师提前准备
4. 课堂流程（原核心课通常 75–90 分钟，新增综合专题可为 120 分钟）
5. 学生数据表
6. 预期结果与科学解释
7. 中英对照板书、教师引导问题
8. 常见误区和实验误差
9. 课堂评价与离堂问题
10. 安全、备用方案、可选延伸与关键英文词汇
