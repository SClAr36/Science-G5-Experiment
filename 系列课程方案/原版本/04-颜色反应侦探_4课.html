颜色反应侦探（4课）

形式：五年级一对一实验课，每课 45–60 分钟。 整理日期：2026-09-07。

返回总目录 ｜ 原合辑与检索背景

核心认识：不同材料混合会给出不同的显色信号；信号是否出现，还取决于混合物中有没有其他干扰成分，以及观察时机。借助已知对照，颜色才能成为证据。

这条路线把前面讨论过的淀粉、维生素 C 和碘钟真正串成一组检测任务；不把这些活动宣称为本次才首次发现的新实验。

A1 · 稀碘液与淀粉显色

核心问题：能不能用一种试剂找出样品中的淀粉？

混合什么、怎样做：教师预配的稀碘液分别与水、糖水和淀粉样品接触。孩子自己滴加并建立对照色卡；剩余时间可用淀粉液画小图案，再显色。

本质与现象：碘／多碘离子与淀粉中的适宜结构形成深色显色复合体系，出现深蓝至蓝黑色。水和糖水不呈同样显色。这不是把淀粉染成另一种永久颜料。

孩子要学会：先用已知样品建立检测规律；一次颜色变化必须与对照一起解释。记住“试剂是观察工具”，不背分子结构。

前后连接：建立可用的深色信号，为下一课研究信号为何消失打基础。

教师准备：使用新鲜、标签明确的含碘材料预配稀液，不把原瓶交给孩子自由分装。依据：ACS：Starch Search、RSC：微量食品淀粉检测。

A2 · 维生素 C 使碘—淀粉体系褪色

核心问题：蓝黑色消失，是不是说明淀粉不见了？

混合什么、怎样做：把同一批碘—淀粉显色液分成两份，分别滴入维生素 C 溶液和相同体积的水；比较颜色变化。先用成分简单的模型溶液，再考虑经过预试的果汁样品。

本质与现象：维生素 C 把显色所需的碘还原为碘离子，深色逐渐褪去；这不能单独证明淀粉被分解。水对照用于排除单纯稀释带来的颜色变浅。

孩子要学会：第三种材料可以改变检测结果；“没有显色”不自动等于“没有被检测的成分”。儿童解释到“维生素 C 先与碘发生作用”即可。

前后连接：知道碘会被维生素 C 消耗后，才容易理解下一课的显色等待。

教师准备：模型样品优先，避免把有本底颜色、其他还原成分的真实果汁结果直接当作精确维生素 C 含量。依据：ACS：Fruit Juice Sleuth，面向儿童的原活动。

A3 · 维生素 C 型碘钟

核心问题：混合后先看不到颜色，为什么过一会儿会突然显色？

混合什么、怎样做：由教师把新鲜含碘材料、维生素 C、淀粉和低浓度双氧水配成已验证的工作液。孩子混合、计时，比较两个在预设范围内不同维生素 C 起始量的样品。

本质与现象：过氧化氢使碘离子重新形成碘，维生素 C 又消耗生成的碘；维生素 C 耗尽后，碘才积累并与淀粉显色。外观先近无色，再突然变深蓝至蓝黑。

孩子要学会：反应可以在信号出现前已经进行；“需要先用完多少材料”与“反应有多快”是不同问题。用先消耗、后积累的图解释即可。

前后连接：把显色、褪色和等待放到同一个解释中；结课用这些认识设计检测。

A4 · 用两种试剂识别三份模型样品

核心问题：怎样用尽量少的测试，辨认三份外观相近的样品？

混合什么、怎样做：候选只设水、淀粉样品、维生素 C 溶液三类。孩子选择稀碘液或已显色的碘—淀粉液进行小量测试，自定顺序，记录并判断编码样品。

本质与现象：沿用 A1 的显色和 A2 的褪色两种特征，不新增一种反应。不同组合得到深色、保留原色或褪色等结果。

孩子要学会：依据多条证据判断，把“猜中了”变成“我能说明为什么”。结论只在教师给定候选范围内成立，不能扩展成鉴别任意无色液体。

前后连接：将前三课的信号和限制变成自己能使用的检测流程。
