# 系列课程方案总目录

**这里集中保存九条四课系列（共36个候选课时）和一份强视觉化学专题，共十份方案。** 01–06、08–10为连续系列；07为可选演示与配套探究库，不另计为已经排定的四课。

每课默认 45–60 分钟，面向一名五年级孩子。儿童目标以观察、比较、因果解释和预测为主；教师需要掌握的微观机制与儿童目标分开写。

## 怎么使用

- 从一条有连续问题的系列开始。物理系列按各自实验主线完整展开，07是另行选用的化学增强专题。
- 第 07 份已注明与原有碘钟、泡沫、喷泉和糖蛇活动的重复关系，避免重复排课。
- 09电路可为01电化学提供接线基础；两条都上时，已经熟练的单灯接通部分缩为复习。
- 每份方案写明实际实验、反应或物理过程、现象与儿童目标；候选阶段尚未完成所有配方和装置的实物预试。
- 酸与小苏打的重复实验不再安排。更早的六课原稿、旧构想和铜—电子转移进阶方案没有纳入本目录。
