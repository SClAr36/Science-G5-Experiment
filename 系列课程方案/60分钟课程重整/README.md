## 体系体现在哪里

**内容主线在模块内闭合。** 例如颜色课的四项活动共用一个显色信号机制；浮力课用同一个排水规律连接测力、沉浮与造船。模块可以一课学完，也可以因确有新问题再深化；课数本身不是系统性的证据。

**学习方法在模块之间积累。** 每课都完成一次“预测—对照或测试—观察—解释—再验证”，但记录保持简短。一张关键对照表、一幅因果箭头或一张标注改动的照片就够，不用长篇填写占满操作时间。

**完成目标可检验。** 下课时孩子应能预测一个没做过的条件变化，并用本课证据说明原因。已经会了就前进；要延长系列，需要新增待解决的问题、不同材料体系或真正耗时的制作任务。

## 时间怎么理解

- **60分钟是主版本**：通常0–4分钟用于简短复习和预测，4–53/54分钟做实验、搭建、比较与随做随讲，最后6–7分钟提取结论并收拾。没有另外藏一段讨论或清理时间。
- **不是反应持续时间表**：一次显色可能只需几秒，安排十几分钟是为了孩子分样、做对照、解释和再验证；不会因此单独排一整课。
- **等待尽量并行**：水电解集气时做另一套显色，解胶等待时做胶条。面团发酵、糖蛇冷却使用明确标注时间的阶段样品；孩子自己刚做的样品不冒充已完成。
- **搭建仍由孩子完成**：教师提前分装、裁危险部件、预试设备，孩子负责关键接线、混合、造船、制鼓、折梁与判断。不能靠教师预装全部成品把不现实的课表“做完”。
- **留有停止规则**：每份写明哪些重复或装饰先缩减、装置异常时怎样保留真实记录。若当天只有45分钟，按该模块挑选两组核心实验和一项简短应用，另排45分钟时间表；不能宣称所有60分钟内容自动适用于45分钟。

这些分钟数是依据步骤和装置条件作出的**备课估算**，尚未记录孩子实际完成时间。首次授课建议只记每个实验实际起止和卡住的位置，用真实数据调整下一次密度；不要再次以“四节看起来很完整”定课数。

## 根据兴趣怎样先选

喜欢mix与颜色，可在已上的 **04颜色反应** 基础上，选 **05凝胶** 或 **02气体第一课**，比较材料成形和快速泡沫两种不同体系。每节都有自己的完整问题。

想继续物理，可选 **08结构第一课**：同一节内完成规律建立与小挑战。声音可先试 **03第一课**；09发光是另备材料后的可选课，不等所有试剂齐备才开始上课。

**选课条件**：依据现有库存记录，浓度未知的旧双氧水不用；氯化钙等已用完品需补充。各模块列的是所需材料，不等于现有库存。碘钟、凝胶、显色电解、发光工作液都要先用最终购得材料预试。酸＋小苏打、已授色散、已有小车与一般溶解活动不重新排入。
