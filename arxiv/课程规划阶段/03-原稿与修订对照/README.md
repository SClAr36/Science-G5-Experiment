01 直接提取用户提供的 Markdown 文段，范围从开头“每课包含”至“给家长的一段话”引用结束；不含随后要求修改的口述说明。原文的章节编号、文字、数字、步骤、附录、表格和原有表述均未修改，也没有插入批注。原稿存档与会话中的该片段逐字核对一致。

02 沿用上一轮三个系列、十三个候选课时的编号，明确每课实际做什么实验、本质是什么反应或物理过程、看见什么、希望孩子学会什么，以及原稿对应位置。它是内容说明稿，配方与装置尚需预试。

03 按原稿六节及附录逐项标明保留、替换、拆分、合并、新增、未采纳及科学说明修正，并明确哪些课复用了同一反应。
