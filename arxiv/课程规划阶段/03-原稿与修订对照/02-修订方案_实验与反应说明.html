系列 A：让变化听指挥（5 课）

总问题：怎样让一个变化在预期条件下出现？各课分别研究触发、催化、显色等待、温度与能量表现，最后完成一次预测与验证。

A1 · 三水合醋酸钠快速结晶与测温（热冰塔）

核心问题：室温液体为什么能被晶种触发，快速结晶并升温？

做什么实验：主材料是水合状态明确的三水合醋酸钠、水、晶种与温度计。教师提前配制、加热并冷却体系；孩子比较加晶种与未加晶种的样品，记录结晶和温度。预试允许时，把冷却后的液体倒在晶种上形成结晶塔。

本质是什么：主实验是结晶放热。溶液中的钠离子、醋酸根和水进入三水合醋酸钠的晶体结构；晶种提供成核起点。这里按结晶／相变过程教学，不能把它用作生成另一类化学物质的证据。

结晶过程示意（不是新物质反应的判定式）：

CH₃COONa（溶液中）＋3H₂O（液） → CH₃COONa·3H₂O（晶体）

预期现象：加晶种的样品快速出现白色晶体并升温；未触发的样品在观察窗口内可能保持液态。

希望孩子学会：用温度计而非手感判断温度变化；理解晶种影响变化的触发；能说明物理变化也可以放热。

与原稿相比：保留热冰；酸与小苏打的混合实验已多次做过，本版移除。纠正“结晶放热证明化学反应”的连接；不原样重复原第 5 课热冰。

准备与边界：原稿“40 g 醋酸钠＋5 mL 水”不直接沿用，先明确水合状态并预试。加热和充分冷却在课前完成；用晶种触发，不用手指触液。依据：RSC：Hot ice、ACS：化学反应中的能量变化。

A2 · 酵母催化过氧化氢分解（彩色大象牙膏）

核心问题：加入酵母后为什么明显产气，泡沫又是怎么形成的？

做什么实验：使用新鲜 3% 或更低浓度双氧水、酵母、少量洗洁精和可选食用色素。比较相同双氧水条件下有、无酵母的样品；再把有、无洗洁精作为可选对照。孩子混合教师分装的材料，记录气泡、泡沫及温度。

本质是什么：酵母中的过氧化氢酶催化过氧化氢分解，主要生成水与氧气；反应放热。洗洁精帮助形成泡膜，色素帮助观察。它不是酵母发酵产生二氧化碳的实验。

2H₂O₂ —过氧化氢酶→ 2H₂O＋O₂↑

预期现象：在给定条件下，加入酵母的样品明显产气；加入洗洁精时气体被泡膜留住，形成泡沫柱。温升大小以实际测量为准。

希望孩子学会：分清反应物、催化剂和帮助显现现象的材料；知道泡沫高度不是氧气体积的直接读数。用对照支持“加入酵母使这个过程更快”。

与原稿相比：将原第 3 课“催化分解”与“大象牙膏拓展”合并，因为它们本来就是同一个反应。主比较改为有、无酵母；不把一勺酵母、一块土豆和不定量二氧化锰的表现直接当作普遍催化能力排名。

准备与边界：先预试课堂实际规模的效果；小用量、敞口、托盘和护目镜，不通过提高双氧水浓度追求更大喷涌。依据：ACS：A Catalyst and the Rate of Reaction。

A3 · 维生素 C 型碘钟（延时突然显色）

核心问题：等待变色时，反应是不是还没开始？

做什么实验：材料体系为过氧化氢、含碘／碘离子的溶液、维生素 C（抗坏血酸）、淀粉和水；由教师配成已验证的低浓度工作液。孩子按固定方式混合和计时；比较同一配方范围内不同维生素 C 起始量的显色等待时间。

本质是什么：这是连续的氧化还原反应与显色过程。酸性条件下，过氧化氢把碘离子氧化成碘；维生素 C 又迅速把生成的碘还原回碘离子。维生素 C 耗尽后，碘／多碘离子才能积累，与淀粉形成深色显色结构。

教师把握机制用的简化反应：

H₂O₂＋2I⁻＋2H⁺ → I₂＋2H₂O

C₆H₈O₆＋I₂ → C₆H₆O₆＋2I⁻＋2H⁺

I₂＋I⁻ ⇌ I₃⁻，碘／多碘离子与淀粉形成显色复合结构。

第二式把维生素 C 的初步氧化产物写作脱氢抗坏血酸；其后在水中的进一步变化不作为本课重点。

预期现象：混合后先保持近无色，经过一段等待后突然显出深蓝至蓝黑色。重复试验的时间会有一定波动。

希望孩子学会：可见信号出现的时刻不等于反应开始的时刻；能用“先被消耗，耗尽后才能积累”解释等待。改变维生素 C 量主要是在改变需要先被消耗的量，不能把时间变化全部说成反应速率改变。

与原稿相比：保留碘钟的延时显色效果，但把原来的碘酸钾—亚硫酸盐体系替换为维生素 C 体系；从原第 3 课拆出一整节，并明确实际研究的变量。

准备与边界：本稿不把原稿未明确浓度的硫酸配方移入课堂；原料身份与工作液浓度要在正式教案中落实。依据：JCE：Vitamin C Clock、Portland State：碘与抗坏血酸的反应。

A4 · 完整化学发光棒的温度比较

核心问题：为什么同款发光棒在不同温度下亮度不同？

做什么实验：使用完整、同款、同色的化学发光棒，在冷水、室温水与经预试的不烫手温水中比较。固定启动时刻、观察背景和拍摄曝光；60 分钟版本可增加蓄光贴作对比。

本质是什么：常见商业发光棒采用过氧草酸酯化学发光。草酸酯与过氧化氢反应，经过高能中间过程把能量传给染料，染料从激发态回到较低能态时发光。具体草酸酯、溶剂和染料依产品而异，因此不虚构一个适用于所有产品的完整反应式。

能量传递示意：

草酸酯＋过氧化氢 → 反应产物＋可转移给染料的能量

染料（激发态） → 染料（较低能态）＋光

蓄光贴主要是先吸收光，再逐渐释放部分能量，属于另一种发光机制。

预期现象：在适宜比较条件下，温暖组通常更亮，冷组较暗；实际亮度和持续时间取决于产品及温度。完整寿命的比较可能超出课时，由教师补充记录。

希望孩子学会：把光与化学能转化联系起来；理解温度会影响这一过程的速度与表现。某一刻更亮，不足以证明总共释放的能量更多。

与原稿相比：这是新增实验，承接原第 2 课“温度影响变化速度”的主题；原泡腾片冷热水比较不再作为主课。发光棒不属于电池实验，也不是荧光灯通电发光。

准备与边界：发光棒保持完整，不拆开取液；先测试可见差异。依据：ACS：Change Is Bright、ACS：Slow the Glow。

A5 · 维生素 C 型碘钟的显色时间预测（三杯接力）

核心问题：能否依据自己的记录，让几杯同时启动的溶液按预期顺序变色？

做什么实验：沿用 A3 的维生素 C 型碘钟。先用两组数据建立初步预测，选择一个变量，固定总液量、温度和操作方式；再同时启动样品并核对显色顺序。45 分钟完成两杯，60 分钟可尝试三杯。

本质是什么：与 A3 完全相同：过氧化氢生成碘，维生素 C 先消耗碘，耗尽后显色。本课新增的是校准、预测和验证，不是另一种化学反应。

预期现象：几杯从近无色依次变成深蓝至蓝黑色；实测先后和等待时间可能偏离预测。

希望孩子学会：依据数据预测；区分反应机制和人为选定的显色目标；发现计量、启动时差和混合方式会影响重复性。目标先是顺序或时间区间，而非要求一次恰好到某一秒。

与原稿相比：把原第 6 课泛泛的自由研究，具体化为碘钟的时间设计任务。它是 A3 的深化，不计作新增反应体系。

准备与边界：沿用 A3 已验证的材料菜单和工作液范围；通过补水保持总液量一致。适用依据与化学机制见 A3。

系列 B：材料怎样长出来（4 课）

总问题：为什么粉末或液体会形成不同的结构，结构又怎样影响外形和手感？三个基础例子分别是气体造成孔洞、长链交联成网、晶体有序生长。

B1 · 糖与小苏打受热形成多孔碳质残留物（糖版法老之蛇）

核心问题：为什么少量固体能长成很大的结构，冷却后却很轻？

做什么实验：采用糖与小苏打版本的室外教师演示。主要受热材料是糖和碳酸氢钠，外部燃烧热源负责供热；燃料及点火操作另按教师验证的演示流程完成。孩子预测、记录形状和生长过程，待样品充分冷却后，用工具和放大镜观察内部结构。

本质是什么：多个过程同时发生。碳酸氢钠受热分解，产生二氧化碳和水蒸气；糖经历热分解、脱水和部分燃烧，形成含碳残留物。气体撑起正在形成的残留结构，留下大量孔洞。

其中一个明确的反应是：

2NaHCO₃ —加热→ Na₂CO₃＋CO₂↑＋H₂O↑

糖的变化是复杂过程，不用“糖全部变成纯碳”的单一方程式代替。黑色残留物含碳质材料、无机盐等，并非纯碳。

预期现象：受热区形成黑色、弯曲、逐渐伸展的多孔结构；冷却后的材料疏松而轻。生长可能需要 10–20 分钟，不承诺几秒完成。

希望孩子学会：区分体积变化与固体质量变化；能用内部孔洞解释“大而轻”；连接气体生成与材料结构。仅凭外形不能证明质量守恒，质量守恒需要明确系统中进出的物质。

与原稿相比：将原附录里的糖版法老之蛇提升为主课，并写清它是燃烧供热、热分解与多孔结构形成的组合，不只是“强烈放热”的另一例。

准备与边界：用户已确认有室外空地；教师先验证场地、防护、等待时间与冷却安排。准备冷却样品以保证孩子当堂可观察；不涉及含汞版本。依据：Science Buddies：Make a Fire Snake。

B2 · 海藻酸钠与钙离子交联成胶（凝胶珠与凝胶虫）

核心问题：为什么液滴进入另一杯液体后，就能形成可夹取的外形？

做什么实验：用教师提前水合的海藻酸钠溶液、适宜的氯化钙溶液和可选食用色素。孩子滴出珠子或拉成细条；比较相近大小、不同停留时间的样品，观察外层与内部状态。

本质是什么：钙离子与海藻酸盐长链上的带负电基团相互作用，连接不同长链，形成能固定大量水的凝胶网络。长链原本就存在；本实验主要发生离子交联，而不是从小分子重新聚合成长链。

交联示意（表示连接关系，不是凝胶的完整分子式）：

2（长链上的 —COO⁻）＋Ca²⁺ ⇌ —COO⁻···Ca²⁺···⁻OOC—

预期现象：溶液接触钙盐后形成凝胶外层，得到彩色珠子或细条。短时间样品可能外层成胶、内部仍较流动；成胶程度随时间和条件变化。

希望孩子学会：用“长链连成网”解释成形；认识钙离子向内部扩散与成胶推进的关系；在相近大小样品中比较停留时间。

与原稿相比：新增材料体系，连接 mix、颜色和造型兴趣。它与大象牙膏的产气反应、与晶体生长都不同。

准备与边界：海藻酸钠水合与溶液预检在课前完成，关键成形与比较由孩子操作；实验材料不入口。依据：ACS：Natural Resources & Synthetic Materials、ACS：Goo Worms。

B3 · 明矾晶种生长实验（硫酸铜为替代材料）

核心问题：为什么同一种溶质有时形成很多小晶体，有时一颗晶体能继续长大？

做什么实验：本版主方案使用明矾、水和晶种，观察教师提前培养的不同阶段样品，比较晶种较少与较多时的生长情况；孩子选择晶种并启动自己的样品。若选择蓝色晶体，则另用原稿的硫酸铜体系替代，不在同一课同时做两套比较。

本质是什么：这是溶液结晶与晶体生长。溶液中的组分进入重复排列的晶格。钾明矾晶体常写作 KAl(SO₄)₂·12H₂O；蓝色硫酸铜晶体常为 CuSO₄·5H₂O。本课不把晶体长大解释成生成了另一类化学物质。

过程示意：

溶液中的组分 → 晶格中的有序排列 → 晶体生长

预期现象：在适宜条件下，晶种逐渐增大并呈现规则晶面；大量成核时可能出现许多小晶体。可见生长通常跨越数天，精美大单晶可能需要更久。

希望孩子学会：分清成核与已有晶体继续生长；理解晶种数量、过饱和程度、温度稳定性与物质供应都影响结果。“慢”不是得到大晶体的充分条件。

与原稿相比：保留原第 5 课晶体生长方向，主材料改为明矾，硫酸铜作为明确的替代选择；取消把“慢速结晶”与“爆炸”当作同一机制的快慢两端。把重复热冰的课时用于不同材料结构的比较。

准备与边界：教师提供预制阶段样品并跨周照料，课堂负责启动与证据比较。现有硫酸铜已用完，采用该替代方案需补充材料并集中回收废液。此课不承诺在一节课内长出大晶体。

B4 · 海藻酸钙凝胶成形与保持形状测试（材料作品）

核心问题：怎样使自己做出的凝胶作品达到指定要求？

做什么实验：沿用 B2 的海藻酸钠与钙盐体系，制作珠子或细条。孩子先确定“可夹起并转移后保持完整”等要求，选停留时间或滴出大小中的一个因素，做两轮比较与调整；同时观察 B3 晶体的进展。

本质是什么：仍是钙离子交联海藻酸盐长链形成凝胶，机制与 B2 相同。本课研究成胶条件、几何形状与可观察性质之间的联系。

预期现象：不同制作条件得到的凝胶，在完整性、形变和转移时的表现上可能不同。作品颜色用于标识和创作，不把颜色本身当作强度原因。

希望孩子学会：先提出可测试要求，再制作与改进；用结构与性质解释选择。能区分 B1 的多孔残留物、B2 的凝胶网络和 B3 的晶体结构。

与原稿相比：把自由研究具体化为材料设计任务。沿用 B2，不新增反应；课堂价值在于孩子自己选变量并检验目标。

准备与边界：固定已验证的材料与用量范围；燃烧演示不进入孩子的自主配方任务。材料机理依据见 B2。

系列 C：让化学通上电（4 课，后续候选）

总问题：化学反应怎样提供电流，电流又怎样驱动物质变化？C2、C3 和 C4 共享水电解这一基础过程，分别观察局部显色、气体产物与装置设计。

C1 · 铜锌水果原电池驱动 LED

核心问题：水果、两种金属和导线为什么能组成电池？

做什么实验：用铜片、锌片、柠檬或已验证水果、连接线、低电流 LED 与万用表搭建原电池。先观察教师预试过的可运行组合，再让孩子组装，比较接通、断开与极性变化，结合读数排查。

本质是什么：锌发生氧化进入溶液，电子通过外部金属电路移动；铜电极提供阴极反应发生的位置。在酸性水果电池的简化教学模型中，氢离子在阴极被还原。

负极：Zn → Zn²⁺＋2e⁻

正极：2H⁺＋2e⁻ → H₂

简化总反应：Zn＋2H⁺ → Zn²⁺＋H₂

真实水果体系中溶解氧等也可能参与阴极反应，气泡未必明显。铜通常不是主要被消耗的金属，不能套用“铜离子析出成铜”的另一种电池模型。

预期现象：合适组合可使低电流 LED 发出微光；断路或连接不合适时不亮。空载测得电压，并不保证接上 LED 后仍能提供足够的电压和电流。

希望孩子学会：把电极、电解质、导线和负载连接成一个系统；知道电能来自整个反应体系。能用电压、极性与连接检查解释成败。

与原稿相比：保留柠檬电池，明确主要反应与铜、锌各自的作用；把“不亮就加柠檬”改为检查负载、电极和连接，并将成功运行的完整装置作为课前准备。

准备与边界：教师先试亮指定 LED；使用低压电路。实验水果和试剂不食用。依据：ACS：Build a Lemon Battery、RSC：Batteries and electrochemical cells。

C2 · 硫酸钠溶液电解与溴百里酚蓝显色

核心问题：为什么通电后，两个电极附近能出现不同颜色？

做什么实验：采用预配的稀硫酸钠 Na₂SO₄ 溶液、溴百里酚蓝（BTB）、经预试的适宜电极与低压电源，在浅层溶液中比较通电、断电及极性变化。湿纸写字是可选改编，完成预试后才纳入。

本质是什么：电能驱动电极附近的水反应。阴极产生氢气与氢氧根，局部偏碱；阳极产生氧气与氢离子，局部偏酸。BTB 的酸式／碱式平衡随局部酸碱条件改变，呈现不同颜色；硫酸钠主要帮助导电。

阴极：2H₂O＋2e⁻ → H₂↑＋2OH⁻

阳极：2H₂O → O₂↑＋4H⁺＋4e⁻

预期现象：在适宜初始条件下，阴极附近逐渐偏蓝，阳极附近偏黄；断电后电极反应停止，但已经形成的颜色仍可能保留并继续扩散。不是给水加电就直接生成颜料。

希望孩子学会：用颜色间接观察局部化学变化；把已学过的酸碱指示剂连接到电极反应。区分“通电造成变化”与“断电立即恢复原状”。

与原稿相比：在原电解水基础上新增了酸碱显色的观察方式，更贴合彩色创作；它与 C3 共享基础电解过程，不是全新种类的电能反应。

准备与边界：选择硫酸钠体系，不用食盐水替代；微量、敞口、适宜低压供电。依据：RSC：Microscale Hoffman apparatus。该来源支持硫酸钠溶液的电解产气与显色，湿纸图案属于待预试改编。

C3 · 水电解及两极气体体积比较

核心问题：没有把水烧开，气体为什么出现，两端为什么可能不一样多？

做什么实验：采用经预试的低压水电解与分别集气装置、适宜电极及硫酸钠电解质。孩子观察通断电、分别记录两极气体体积；不在本课混合或点燃所收集气体。

本质是什么：电流驱动水分解。在理想主反应条件下：

2H₂O —通电→ 2H₂↑＋O₂↑

金属导线中主要靠电子移动传导电流，溶液中主要靠离子迁移。反应式表示氢气与氧气的物质的量之比为 2:1；同温同压并忽略相关误差时，体积比也接近 2:1。

预期现象：通电后两极产气，断电后持续产气停止；适宜装置中一端收集体积较大。漏气、气体溶解及电极副反应会影响实际读数。

希望孩子学会：区分水沸腾产生的水蒸气与电解产生的新物质；用原子模型理解组成和比例。气泡与体积比是证据，不能只看气泡就声称已经独立检验出气体身份。

与原稿相比：保留电解水，改为选择合适电解质、电极和集气装置后检验体积关系；不直接承诺原“小苏打＋铅笔芯”装置会得到纯净且精确 2:1 的气体。不安排氢气点燃、氧气复燃的环节。

准备与边界：教师课前验证产气与集气效果，课堂规模按可见证据确定。依据：ACS：Electrolysis of Water。

C4 · 电解显色区域控制（电化学图案）

核心问题：能否让颜色在预期区域出现，而不是随机扩散成一片？

做什么实验：沿用 C2 已验证的硫酸钠—BTB 电解体系。孩子设计简单区域，选择电极位置或通电时长中的一个因素，比较显色区域和扩散，再调整。浅层液体版本为基础，湿纸版只有通过预试后才启用。

本质是什么：仍是电极附近的水反应改变局部酸碱性，BTB 报告变化；后续图案还受到扩散、混合和装置几何的影响。它与 C2 是同一反应体系。

预期现象：电极附近形成蓝／黄等显色区域，区域的位置和范围随布置与通电条件变化；边界可能逐渐变模糊。

希望孩子学会：把电流、局部反应、颜色信号与扩散放在同一个解释中；通过可比较的变量改进自己的图案，说明结果的局限。

与原稿相比：将原第 6 课自主研究延伸为具体电化学作品任务。新增的是设计任务，不增加一种基础反应。

准备与边界：固定已验证的电压、配方与规模，主要研究位置和时间；不以提高电压来追求效果。基础机理依据见 C2。
