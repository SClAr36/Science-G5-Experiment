更新：2026-09-06。 每次 45–60 分钟，一对一家庭实验课。学校内容按需要简短复习，计入总时长。用户已确认有室外空地，可考虑教师演示。

设计取向

孩子先遇到一个值得追问的现象：液体瞬间结晶、泡沫自己长出来、透明溶液突然变深蓝、粉末长成黑蛇、液滴变成凝胶珠。接着让孩子亲自改变一个条件，看看现象是否按预测变化，再用模型解释。

每课保留一个主现象和一个关键对照；45 分钟版本能完成操作、解释和收拾，60 分钟版本增加一轮验证或改造。配液、热冰的加热与冷却、晶种培养等长时间准备由教师提前完成，保留触发、混合、成形、测量和判断给孩子。

四至五节课围绕一个总问题推进。数学与科学方法在孩子需要比较时进入：用时间、温度、滴数、图像和比例回答刚产生的疑问。

系列 总问题 主要现象 逐步建立的联系
A · 让变化听指挥｜5 课 怎样让变化在预期条件下出现？ 热冰塔、彩色泡沫、碘钟、化学冷光、变色接力 触发条件 → 速度与显示信号 → 能量变化 → 预测与控制
B · 材料怎样长出来｜4 课 为什么少量材料能变成不同形状和手感的作品？ 糖版法老之蛇、凝胶虫与软心珠、宝石晶体、材料作品 气体形成孔洞 → 分子长链交联 → 晶体有序生长 → 结构与性质
C · 让化学通上电｜4 课 化学怎样提供电，又怎样被电驱动？ 水果电池微光、通电显色图案、电极产气、电化学作品 电池供能 → 电流改变物质 → 产物证据 → 装置设计

优先展开系列 A；系列 B 最能延续混合、造型和美术兴趣，并安排用户特别感兴趣的糖版法老之蛇。系列 C 作为下一轮备选，需要额外准备并试运行低压电路。三条是可选择的连续主题，不要求全部依次上完。

系列 A：让变化听指挥（5 课）

A1 · 倒出一座热冰塔

  • 核心问题：室温液体为什么能突然变成固体，而且变热？
  • 实验：用教师提前准备并冷却的醋酸钠体系，观察晶种触发和未触发的对照；条件合适时由孩子把冷却后的液体倒在晶种上，形成白色结晶塔，同时记录温度变化。
  • 孩子要发现的规律：液体在室温下可能保持暂时稳定，合适的晶种能触发快速结晶；结晶过程可以放热。
  • 原理关联：结晶（crystallization）、成核（nucleation）、亚稳态（metastable state）、热量转移。调用过去结晶与热传递的证据，认识温度变化并不单独证明形成了新物质。
  • 与下一课连接：这次“长出来”的是晶体；下一课看起来也在长，里面却主要多出了气泡。
  • 课前关键：明确原料为哪种水合状态，优先用标签完整的三水合醋酸钠方案，完成配液、加热和冷却预实验。旧库存含水量不明；用户原稿的“40 g 醋酸钠＋5 mL 水”不能跨原料直接使用。晶种触发，温度计测温，不用手指触液或触摸高温容器来判断。

依据：RSC：Hot ice。

A2 · 彩色大象牙膏：泡沫从哪里来？

  • 核心问题：加入一点酵母，为什么液体会涌出泡沫？
  • 实验：新鲜 3% 双氧水的酵母催化分解，以相同原料的有、无酵母对照寻找产气证据，再加入泡膜因素进行解释。孩子负责定量取用教师分装的材料、混合、计时与记录；泡沫可加少量颜色增加可见性。
  • 孩子要发现的规律：酵母中的过氧化氢酶能明显加快这一分解过程；洗洁精帮助留住气体，因此泡沫高度同时受产气与泡膜保持能力影响。
  • 原理关联：分解（decomposition）、催化剂（catalyst）、反应速率（reaction rate）、放热（exothermic）。催化剂提供另一条反应路径，不能理解成“给反应增加能量”。
  • 与下一课连接：有时变化很快且立刻可见；下一课中，反应先进行一段时间，颜色才突然出现。
  • 课前关键：小用量、敞口、托盘和护目镜；只用新买且标签完整的 3% 或更低浓度产品。把预实验的实际效果作为预期，不承诺复现网络高浓度版本的巨大喷涌。二氧化锰粉末不进入孩子自由混合的材料盘。

依据：ACS：A Catalyst and the Rate of Reaction。

A3 · 魔法药水倒计时

  • 核心问题：为什么看起来没有变化，几秒或几十秒后却突然变色？
  • 实验：采用教师预配、预先验证的低浓度维生素 C 型碘钟。先体验一次突然显色，再比较两个条件的显色等待时间；先固定其余条件研究一种因素。
  • 孩子要发现的规律：在显色之前也有反应发生。生成的碘先被维生素 C 消耗，维生素 C 耗尽后，碘才积累并与淀粉显色。
  • 原理关联：连续反应、物质消耗、显色阈值、间接证据。改变维生素 C 的起始量会改变等待被消耗的量，不能把所有等待时间变化都解释成反应速率改变。
  • 与下一课连接：现在能用“何时变色”观察过程；下一课用亮度变化观察化学过程。
  • 课前关键：具体配方由试运行确定；使用新鲜、浓度明确的原料和教师预配液。原稿中未注明准确浓度的硫酸及亚硫酸盐配方不直接移入这节课。

依据：JCE：Tick Tock, a Vitamin C Clock。

A4 · 化学冷光：怎样让它更亮，又怎样让它更持久？

  • 核心问题：为什么同款发光棒在不同温度下亮度不同？
  • 实验：比较完整同款化学发光棒在冷水、室温水和不烫手温水中的亮度；固定背景、距离和拍摄曝光。可用蓄光贴作短对比，区分先吸收光再发光与化学反应发光。
  • 孩子要发现的规律：在这一体系中，温度会影响化学变化速度和发光表现；某一时刻更亮，不能直接等同于总能量更多。
  • 原理关联：化学发光（chemiluminescence）、反应速度、能量转化。把“能量怎样转移”与“过程进行得多快”分开思考。
  • 与下一课连接：选择合适的可见信号，试着设计一次时间可预测的化学展示。
  • 课前关键：先试出能明显比较的温度范围，发光棒保持完整。整段发光寿命可能超过课时，后续记录由教师完成；不把一小时内的亮度对比写成已经验证了完整寿命。

依据：ACS：Slow the Glow。

A5 · 化学变色接力：让三杯按顺序变色

  • 核心问题：能否根据之前的数据，让几杯溶液按自己预测的先后顺序显色？
  • 实验：使用 A3 已验证的反应，在固定总液量、温度与操作方式下选择一个变量。先做两次校准，再让三杯同时开始、按预定先后显色，记录实际顺序和时间。
  • 孩子要发现的规律：数据可以用于预测；预测与实测会有偏差，需要检查计量、启动时间和混合方式。稳定重现比偶然碰巧成功更有解释力。
  • 原理关联：控制变量、校准（calibration）、重复性（repeatability）、证据支持预测。可以联系孩子的音乐节奏兴趣，把显色当作几个视觉节拍，但目标先定为顺序或时间区间。
  • 课时边界：45 分钟完成两杯的预测与验证；延长到 60 分钟再做三杯接力。固定材料菜单和总用量，不以喷得最高、压力最大为目标。

系列 B：材料怎样长出来（4 课）

B1 · 糖版法老之蛇：长出来的体积从哪里来？

  • 核心问题：少量粉末为什么能长成很大一条黑蛇，冷却后却很轻？
  • 实验：保留糖与小苏打版的室外教师演示。孩子先画出预测，记录生长过程与外形变化；充分冷却并经教师确认后，用工具和放大镜观察多孔残留物，与海绵等多孔材料比较。
  • 孩子要发现的规律：气体可以把材料撑成含大量孔洞的结构，体积变大并不意味着凭空多出同样比例的固体物质。
  • 原理关联：热分解（thermal decomposition）、燃烧供热、气体生成、多孔结构（porous structure）、结构与性质。黑蛇是含碳等成分的多孔残留物，不把它简单说成“全部是纯碳”。
  • 与下一课连接：黑蛇形成了多孔骨架；下一课让液体中的分子长链连接成能保持形状的网。
  • 课前关键：用户已确认有室外空地；仍需按选定糖版流程检查耐热台面、灭火条件、围观距离和天气，并先做小规模预实验。这一现象可能需要 10–20 分钟逐渐长成，冷却另占时间；备好已冷却样品供观察。燃料及点火由教师管理，不安排孩子配燃料、点火或补燃料。此处不指含汞版本。

依据：Science Buddies：Make a Fire Snake。

B2 · 滴水成珠、拉出彩色凝胶虫

  • 核心问题：两种液体接触，为什么能形成可以夹起来的珠子和细条？
  • 实验：用海藻酸钠与适宜的钙盐溶液制作彩色凝胶珠和细条。选取相近大小的珠子，在不同时间取出，比较外层与内部的状态。
  • 孩子要发现的规律：接触并不总会产生同一种“混合结果”；凝胶形成可以从表面向内部推进，停留时间会影响成形情况。
  • 原理关联：聚合物（polymer）、交联（cross-linking）、扩散（diffusion）。这里主要是把已有长链连接成网络，不能说原料从小分子凭空变出了新的长链。
  • 与下一课连接：凝胶用网络保持形状；晶体的规则外形来自另一种内部排列。
  • 课前关键：教师提前完成海藻酸钠水合与溶液预检，保留滴珠、拉丝、取样和判断给孩子。实验材料不入口。

依据：ACS：Goo Worms。

B3 · 种一颗宝石：为什么会长出规则的面？

  • 核心问题：同一份溶质，为什么有时形成许多小晶体，有时能让一颗晶体继续长大？
  • 实验：观察教师提前培养的不同阶段晶体，比较少量晶种与许多晶种的样品；孩子选择晶种，启动自己的晶体生长。明矾可作主材料；蓝色硫酸铜晶体可保留为使用专用器具、集中回收废液的教师指导选项。
  • 孩子要发现的规律：晶体需要适宜的溶液条件和生长时间；成核数量、生长条件与可用溶质共同影响结果。“慢”本身不是保证长出大晶体的充分条件。
  • 原理关联：饱和与过饱和、成核、生长、晶体中的重复有序排列。与过去快速蒸发获得晶体的经历连接，这次研究晶种和后续生长。
  • 与下一课连接：比较已经见过的多孔残留物、凝胶和晶体，选择一种结构制作作品。
  • 课前关键：课堂完成启动和已有样品比较，跨周照料与照片记录由教师负责，不依赖家庭每天照料。大单晶的完成时间不承诺为固定 3–7 天。硫酸铜库存已用掉，需新购标签完整材料；不触摸、品尝晶体或任意排放铜盐废液。

B4 · 材料作品实验室

  • 核心问题：想得到指定的形状和手感，应该选择哪种内部结构与制作条件？
  • 实验：观察 B3 晶体的实际进展，再用 B2 的凝胶体系制作一件彩色作品；预先规定一个可测试要求，例如能夹起并转移后保持形状。比较改变一个条件前后的表现，并为作品画出内部结构示意。
  • 孩子要发现的规律：看起来都在“长大”的现象可以由不同机制产生。选择材料与操作条件时，需要依据它们的性质。
  • 原理关联：气体占据孔洞、长链连接成网、晶体有序排列三个模型；结构与功能、设计—测试—改进。
  • 课时边界：选一种凝胶作品完成两轮尝试即可；燃烧不进入孩子的开放设计任务。

系列 C：让化学通上电（4 课，后续候选）

C1 · 水果里能接出一盏微光灯吗？

  • 核心问题：水果、两种金属和导线怎样共同成为电池？
  • 实验：用教师预先试亮的铜锌水果电池组合驱动低电流 LED，再比较断开、接通和极性变化。万用表用于解释结果和排查，灯是否发亮是可见的任务目标。
  • 孩子要发现的规律：需要合适的电极、电解质和闭合电路；产生电压不等于能向任意负载提供足够电流。
  • 原理关联：原电池（galvanic cell）、氧化还原（redox）、电路与负载。能量来自整个反应体系，不能说成水果独自储存了现成的电。
  • 课前关键：新鲜铜锌电极、低电流 LED 与完整电路预试。不能把“不亮就一直增加柠檬”当作唯一排错方法。

依据：ACS：Build a Lemon Battery。

C2 · 用电写出彩色图案

  • 核心问题：没有画笔蘸颜料，电极附近为什么会出现不同颜色？
  • 实验：采用经预试的微量硫酸钠—酸碱指示剂体系，在浅层液体或湿纸上观察通电显色；比较断电、通电与改变极性的情况。
  • 孩子要发现的规律：电流可以驱动电极附近的化学变化，指示剂让局部酸碱变化可见。
  • 原理关联：电解（electrolysis）、电极反应、酸碱指示剂。调用此前紫甘蓝变色的理解，把电极过程连接到熟悉的颜色证据。
  • 课前关键：具体器材与湿纸版本需要先验证；使用教师配制的硫酸钠体系，不用食盐水替代。低压、限流或适宜电池供电，微量敞口观察。

依据：RSC：Electrolysis using a microscale Hoffman apparatus。该来源支持硫酸钠体系的产气与显色；图案形式是待预试的课程改编。

C3 · 给水通电，气泡是水蒸气吗？

  • 核心问题：没有把水烧开，为什么两个电极上也能产生气泡？
  • 实验：使用预试的水电解装置，比较通电与断电，观察两极气体并在合适装置中比较体积。用已学原子模型解释水分解，明确观察到的气泡只是产气证据的一部分。
  • 孩子要发现的规律：电能能够驱动水分解；适宜条件下氢气与氧气的体积接近 2:1。实测偏差需要结合装置、漏气、溶解与副反应分析。
  • 原理关联：物质组成、原子守恒、电能驱动变化。不能把冒泡等同于沸腾，也不能只根据气泡就声称已经检验了气体身份。
  • 课前关键：不照搬“小苏打水＋任意铅笔芯”并承诺干净、精确的 2:1。选择适宜电解质与电极，先验证可见气量；本系列不安排点燃或混合所收集的气体。

依据：ACS：Electrolysis of Water。

C4 · 做一张能被电改变的颜色作品

  • 核心问题：能否利用电极位置和通电时间，让图案在预期区域出现？
  • 实验：沿用 C2 已验证的装置，由孩子设计简单图案或显色区域，选择电极位置或通电时间中的一个因素测试，再调整作品。
  • 孩子要发现的规律：电路的安排影响反应发生的位置，作品可以用可比较的条件进行设计。
  • 原理关联：电路、局部化学变化、可见信号、工程设计；用图说明电池提供能量、导线传递电流、电极处发生变化、指示剂显示结果。
  • 课时边界：沿用已验证的配方与电压；研究位置和时间，不通过提高电压或增加未知试剂追求更强效果。

原稿需要改正的连接

  1. 热冰属于结晶放热，不能作为发生化学反应的证明。 若同课比较热冰与吸热混合过程，标题宜写“物质变化为什么会变冷变热”。
  2. 小苏打、柠檬酸与水的降温是整个混合、溶解与反应过程的净热效应。 可以说体系从周围吸收热量，不能仅凭摸杯壁就分离各步贡献。涉及化学键时，断键吸能、成键放能，总变化取决于净结果与所处环境，不能笼统说“吸热就是把热存进化学键”。依据：ACS：Energy Changes in Chemical Reactions。
  3. 催化剂改变路径和速度，不改变同一反应前后状态的能量差。 不能把“降低活化能”说成“减少这次反应总共释放的能量”。酵母、土豆与二氧化锰不同用量的对比，只能描述给定条件下的表现，不能据此对三种催化剂作普遍强弱排名；外观不变也不能独自证明催化剂未被消耗。依据：OpenStax：Catalysis。
  4. 大晶体不是“能量慢慢释放”的必然结果。 成核、生长、过饱和程度和材料供应共同影响晶体；晶体生长与爆炸不构成同一种机制的快慢两端。
  5. 水果电池与电解水不是同一个反应直接倒过来。 两者可比较能量转化方向，但反应物、产物和装置不同；在金属导线中主要是电子传导，在溶液中主要靠离子迁移导电。
  6. 原稿的 Whoosh、胀破袋、弹盖、粉尘火球和镁条强光不列入当前家庭课任务。 普通塑料瓶加酒精再点火的写法省略了关键设备与防护条件；专业演示有专门装置和场地要求，教师操作本身并不能代替这些条件。糖版法老之蛇单独作为已确认室外场地的教师演示候选，不把火焰与爆破项目汇成“安全备选实验”。依据：RSC：Whoosh bottle 的专门要求。

材料与时间上的实际取舍

  • 热冰：采购水合状态明确的材料或适宜相变体系，整套预实验后再安排。加热、降温不占孩子主要实验时间，孩子负责触发、倾倒、观察与测温。
  • 泡沫与碘钟：采购新鲜、标签完整的双氧水及显色材料；不依赖分装半年、浓度未知的旧液体。
  • 法老之蛇：优先确认糖版小规模现场效果、等待时间及燃烧后冷却安排，不追求最长或最大。室外条件不合适时调整课序，使用冷却样品与现象记录作衔接。
  • 晶体：预制阶段样品，教师跨周照料；硫酸铜已经用完，不按现有库存计算。用同一种条件明确的材料做比较。
  • 电化学：需要合适电极、连接件、低电流 LED、测量工具与预配显色体系；先解决完整装置的可重复运行，再把它作为课堂看点。
  • 本轮已核对教学来源和概念连接，尚未进行实物配方与装置测试。正式选定课程后，再完成用量、器材、45/60 分钟时间线与故障备用。

给家长的课程说明

新阶段每次课约 45–60 分钟，从孩子感兴趣的明显变化开始，例如瞬间结晶、泡沫生长、突然变色或液体成胶。每个系列用四至五节课围绕一个总问题推进：孩子先预测，再亲手改变一个条件，通过观察和测量解释结果，并逐渐尝试设计能重复出现的现象。每节课同时留下“我看到了什么”“我怎样解释”“下一次我预测什么”的简短记录。室外燃烧演示由教师操作，孩子承担预测、记录和冷却后的结构观察；其余适合的关键步骤尽量由孩子完成。
