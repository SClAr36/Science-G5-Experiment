成人课前完成

  1. 从饮料瓶身较直处切出 4 个高约 4–5 cm 的塑料圆环；剪口包一圈胶带，确保无尖边。每环画一支正向箭头。
  2. 做一个空环预试，确认可架在接水杯上。再做一个示例铰链瓣：柔软塑料片只固定一边，其余三边可开合；示例只展示原理，不给学生标准答案。
  3. 把清水染成很淡的红色。太深会染衣物，且不增加实验价值。
  4. 晴天时预试 UV 感光珠 10 秒能否变色；阴雨天准备能照到阳光的位置，或改做彩纸日晒长期方案。
  5. 把 A4 便签写成系统卡和路线卡，详见 0–15 与 75–92 分钟。

一、课程定位与学习目标

  • 对应学校单元：Unit 4 Life Science
  • 对应材料：08–11 人体系统 Notes；05 Study Guide for Biology Test
  • 核心问题：人体有数以万亿计的细胞，哪些系统合作把氧气和养分送到细胞，又怎样保护细胞免受外界伤害？
    How do body systems work together to deliver oxygen and nutrients to cells and protect them from harm?

学校课件中的人体系统不逐页背诵。本课用两个工程问题覆盖必要知识：

细胞 cell → 组织 tissue → 器官 organ → 器官系统 organ system → 生物体 organism

运输任务：
呼吸系统 respiratory system 把氧气带入肺
循环系统 circulatory system 用心脏、血液、血管完成全身配送
消化系统 digestive system 把食物分解成可吸收养分
泌尿系统 urinary system 清除血液中的部分废物、调节水盐

保护与控制：
皮肤系统 integumentary system 构成外部屏障
免疫系统 immune system 识别并处理病原体
神经系统 nervous system 快速传递信息、协调反应
骨骼肌肉系统 skeletal and muscular systems 支撑、保护并产生运动

学生应能

  1. 用实例说出细胞—组织—器官—器官系统—生物体的层级关系。
  2. 把八个主要人体系统与一句核心功能配对，并举出至少两组系统协作。
  3. 设计、测试并改进一个人工单向瓣膜，使 100 mL 水能正向通过、反向尽量少漏。
  4. 按正确顺序走完氧气从空气到细胞、二氧化碳从细胞回到空气的路线。
  5. 用 UV 感光珠数据比较材料的紫外线屏蔽效果，说明皮肤屏障仍需要衣物、遮阴和防晒措施协助。
  6. 理解本课模型只表示系统功能，不等于真实器官的形状、材料和全部工作过程。

0–15 分钟：任务 1——给细胞派送物资的系统卡

实验目的：用纸卡建立身体层级和系统合作图，先回答“谁负责什么”，再进入心脏瓣膜设计。

重要知识点：多个相似细胞组成组织（tissue），不同组织组成器官（organ），多个器官合作成为器官系统（organ system）。系统不是各自独立工作，而是共同维持稳态（homeostasis）。

15–55 分钟：实验 1——设计能防止倒流的人工心脏瓣膜

实验目的：在相同测试环中设计一个能正向开启、反向关闭的瓣膜，用通过量和漏水量评价性能。

重要知识点：心脏是肌肉泵，**瓣膜（valve）**靠两侧压力差开合，使血液大体沿一个方向流动。工程标准必须同时考虑正向阻力和反向泄漏；只会堵住两边的“阀门”不合格。

75–92 分钟：任务 2——氧气和二氧化碳往返路线

实验目的：用红蓝路线卡让一个“血细胞令牌”走完肺循环和体循环，解释呼吸系统与循环系统怎样连续合作。

重要知识点：氧气在肺泡与毛细血管之间扩散进入血液；左心把富氧血送往全身，细胞使用氧气并产生二氧化碳；右心把血送回肺。动脉和静脉按血流离开心脏或回到心脏命名，不能简单等同“含氧/缺氧”。

92–116 分钟：实验 2——哪种材料更能屏蔽 UV？

实验目的：在相同阳光和曝光时间下，用 UV 感光珠比较裸露、棉布、透明塑料、铝箔和防晒霜的屏蔽效果。

重要知识点：**紫外线（ultraviolet radiation, UV）是人眼看不见的电磁辐射，过量会损伤皮肤细胞。皮肤是皮肤系统（integumentary system）**的屏障，但衣物、遮阴和防晒材料可减少到达皮肤的 UV。UV 珠只显示相对暴露，不是人体伤害计量器。

四、安全、误差与现场备用

  • 所有塑料瓶切割由成人课前完成，切口包胶带；学生不使用美工刀。
  • 地面有水立即擦干；测试始终在深托盘内进行，食用色素水不饮用。
  • 人工瓣膜不是医疗器械，不能放入口鼻或用于任何人体测试。
  • UV 珠有误吞风险，始终封在袋中，远离三岁以下儿童；实验后清点数量。
  • 只用自然阳光短时测试；不直视太阳。若用黑光灯，按设备说明佩戴护目镜并避免长时间照皮肤。
  • 防晒霜实验用于比较材料，不评价品牌或给出医疗建议；皮肤敏感者不直接接触。
  • 瓣膜边缘漏水必须记入数据，不把它删成“操作失误”；先改密封再复测。
  • UV 材料有缝隙会造成假阳性；所有覆盖应完整，并让五组同时进出阳光。
  • 阴雨天 UV 珠不明显时，改用教师预拍数据或启动彩纸 3–4 小时替代，不伪造颜色等级。
